## New transferable design: provenance-separated variant-aware generative phrase grammar
1. Define `SourceWitness(witness_id, holding_institution, source_kind, date_range, scan_url, page_id, measure_id, verified_image)`. Every extracted reading is keyed to a witness. Distinguish manuscript *copy*, early print and later editor. Never silently normalize conflicting pitches, ties or ornament signs.
2. Encode each reading as `Reading(witness_id, voice, onset: Fraction, duration: Fraction, spelled_pitch, articulation, tie_from, ornament, verification)`. Store missing/unreadable as `UNKNOWN`; never interpolate it as a source fact. A witness-to-witness collation yields a graph of aligned onset regions and `equal|different|uncertain` edges.
3. Extract compositional *function* only after direct score verification: `PhrasePlan(metrical_grid, bass_targets, harmony_regions, salient_melody, cadence_goal, voice_roles)`. A waltz-inspired **original** grammar may use 3/4 with a low bass event followed by upper-register chordal attacks, but this is a generic model and **not a claim that any particular Op.69 No.2 measure does so**.
4. Generate a 4–8-bar phrase by first choosing a terminal harmonic goal, then bass/harmonic route, then salient melody anchors. For each two-bar pair, preserve at least two musical invariants (e.g. accent rhythm and contour) and vary one controlled parameter (interval width, register, bass route, metric displacement). Explicitly tag reprises; do not mistake metadata differences for motivic development.
5. Subdivide selected spans into 8th/16th/32nd-note events only if they serve approach, neighbor, turn or directed arrival; ensure exact rational durations. Preserve structural anchors; never fill every beat merely to maximize density.
6. Analyze NCTs on sounding intervals *including harmony changes without reattacks*. Candidate labels require spelling, metric accent, local harmonic vocabulary, previous/next voice event and resolution; retain ambiguity. A held note across a chord boundary is not automatically a suspension. Cross-voice clashes need context-sensitive analysis, not unconditional prohibition.
7. **Witness-conditioned synthesis**: keep stylistic rule priors separate from source readings. If two witnesses differ, derive two candidate structural readings with provenance and only promote a common generative rule when both support it, or explicitly condition the rule on one witness. This prevents posthumous editorial readings from being falsely treated as autograph evidence.

## Executable validation specification (NOT executed in this run)
- Witness isolation: identical timestamps in different editions must not merge into one voice; reject readings without provenance.
- Temporal coverage: each voice covers the chosen window with explicit rests; every sounding interval is partitioned by a contiguous nonoverlapping harmony grid or explicit UNKNOWN.
- Ties: reject rest-ties, nonadjacent ties, changed-pitch ties; count tied continuation as one attack.
- NCT adversarial cases: a chordal ninth must not automatically become a passing tone; a reattacked note across a boundary must not become a suspension; chromatic neighbor requires spelling and return; uncertain harmonic function remains UNKNOWN.
- Motif tests: changing only witness metadata fails; literal reprise only passes with explicit reprise flag; controlled transformation must preserve two meaningful invariants and reach a declared phrase goal.
- Source fidelity: each claimed source-note must have image, page, measure, witness ID and manual verification status.
