## Proposed original compositional grammar — not Chopin transcription
1. `Form -> 2-bar phrase -> harmonic spans -> independent bass/inner-melody/RH gesture clocks -> ornament layer`. In a 3/4 slow waltz, model each voice's occupancy independently; **do not** sum simultaneous voices into a single 3/4 ledger.
2. LH voice A `bass_anchor` and LH voice B `sustained_countermelody` each get onset/duration/pitch/continuity. The expressive long note may cross beat 2/3 while the other voice changes; a single arpeggio/chord event cannot encode this.
3. RH can start with rests and short dyadic gestures. Avoid compulsory full-bar perpetual sixteenth notes; density is a section-level expressive decision.
4. Two-bar motif transform stores `contour, rhythm, cadence_goal, bass_path, register, sustained_voice_goal`. A repeat preserves at least one motif invariant and changes one consequential harmonic/structural parameter; exact reprise is a separate explicit state.
5. Harmony audit computes the sounding set at *every onset and chord boundary*, including held notes begun before the boundary. Label dissonances as candidates `passing, neighbor, appoggiatura, suspension, anticipation, unresolved`. To certify a suspension, check previous consonance, actual uninterrupted hold, metric placement and resolution; never infer it from pitch class alone. The chord label alone does not determine acceptability of expressive dissonance.
6. Ornament objects include `source_witness, glyph, anchor, notated_grace_value, execution_policy, uncertainty`. A Kullak editorial suggestion, National Edition performance recommendation and a first-edition notation reading are different evidence classes.
7. For 3/4 exact-time engine, use `fractions.Fraction`: 6 eighths, 12 sixteenths, 24 thirty-seconds; unmeasured grace events occupy zero notated metrical duration but have a separate optional playback scheduler.
