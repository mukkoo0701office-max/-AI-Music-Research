## Specific v4 code audit
The engine generates 32-note, two-bar contour using 8 groups of 4 repeated ±1 semitone steps. Its `contour` uses `out.extend(out[-1]+direction for _ in range(4))`: the generator's `out[-1]` is evaluated as extension proceeds, making a four-step chromatic run. This is a deterministic fast-layer mechanism, **not an independently validated harmonic contrapuntal generator**. The `beats` anchor score checks only every fourth fast-layer pitch; no sustained bass or inner-voice event list, harmonic boundary splitting, note-specific dissonance classification, accent mask, or 2-bar successor invariant is implemented. Existing v4 is not modified in this study; no false integration claim.

## Implementable successor specification (original algorithm, NOT Chopin notes)
1. Source-tagged `meter`, `harmony_windows`, and event `(voice,onset,duration,pitch,accent,motif,source_status)` use exact rational whole-note units; reject missing source or meter. Validate durations, rests, overlaps per voice, and simultaneous cross-voice sounding events.
2. Generate macro cadence targets and bass/harmonic plan first; assign foreground melody anchors and independent inner-voice guide-tone destinations; only then fill a rhythmic surface with dotted/inverted-dotted gestures or sixteenth/thirty-second subdivisions. Such patterns are **compositional options**, not asserted transcriptions.
3. For every harmony change inside a held event, split its analytical sounding span at the boundary while preserving original note onset; label whether a tie is notationally required separately from slur phrasing. Audit the dissonance on each side.
4. Nonharmonic classification returns `PASSING`, `NEIGHBOR`, `APPOGGIATURA_CANDIDATE`, `SUSPENSION_CANDIDATE`, `ANTICIPATION_CANDIDATE`, `CHORD_TONE`, or `UNKNOWN` only after testing current sounding harmony, adjacent notes in the same voice, metric stress, and preparation/resolution. Never equate a stepwise contour with a confirmed passing tone.
5. Two-bar development is a constrained transformation: preserve at least one structural anchor and change >=2 independently measured descriptors (accent phase, register, density, contour). Reject exact repeated three-note cells as the only developmental mechanism. This gate detects trivial repetition, not musical quality.
6. Counterpoint audit at every event onset and harmonic boundary: inspect voice crossing, low-register clashes, guide-tone continuity, parallel perfect intervals, and accented dissonance; record justified stylistic exceptions, not blanket bans.
7. Separate `source_status=original_verified` from `secondary_report`, `synthetic`, and `unverified`; never allow synthetic test notes to masquerade as source evidence.
