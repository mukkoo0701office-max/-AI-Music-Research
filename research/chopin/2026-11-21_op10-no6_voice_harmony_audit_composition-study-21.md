## 直接読めた構造（転写の事実に限定）
1. m.1：6/8。左手の16分音符は12イベント、6+6に分けられ、同時に低音 `2.E-`（付点二分）が別spineで保持される。右手には `[4.g-` と `4g-]`、さらに短い16分イベントがあり、**同じ左手に独立した速い内声と保持低音**が共存する。先頭の `*^` を無視して単一列に足すと時間が破綻する。
2. m.2–3：左手の16分12音という密度は維持されるが、m.2は `16c-`,`16d-`,`16B-` など、m.3は `16A-`,`16B-`,`16Gn` などに変わる。右手spineにはm.2で `4.b-`, `4.a-`, `8.e-`、m.3で `[4.cc-`, `4cc-`, `16b-` 等が見える。これは**音価密度一定≠音高・旋律アンカー一定**という限定的な証拠であり、全体の和声機能を確定するものではない。
3. m.4：左手16分12イベントと `2.D-X`（付点二分の低音保持）。右手には `4.rCCCyy` と `4rGGGyy` の不可視休符があり、別spineの時刻を埋める。不可視だからといって時間から削除してはならない。m.4–5の転写には `problem:mixed beam` があるため連桁復元は未確定。
4. m.21に `*k[f#c#g#d#]`、m.29に `*k[b-e-a-d-g-c-]` がある。**転写上、m.21–28の調号は4シャープ、m.29で6フラットに戻る**。m.21には `fp` と `Legato`、m.29には複数の和音と16分音群がある。4シャープ調号を見ただけで確定的な転調機能・情緒・全和音を断定しない。
5. m.41–43は冒頭の16分音型と低音配置に対応する転写トークンが再登場する（m.41 `16B-LL`、`2.E-`、m.42 `16c-LL`、`2.F`、m.43 `16A-LL`、`2.Dn`）。**再帰的なテクスチュア**を示唆するが、原版画像と逐音の比較がないため厳密な再現・再現部の範囲は未確定。

## 作曲への抽象化（以下はすべて独自生成規則。ショパンの音符の転記ではない）
### 1. 三層＋和声時計
入力は4–8小節のフレーズ弧、低音機能、旋律アンカー、内声の密度、各声部の拍位置。まず旋律の到達点と低音の和声更新時刻を決め、その間を内声の16分運動で連結する。内声の各16分で和音を更新しない。各層は同一の有理数時間グリッド上で独立生成する。
### 2. 2小節変形は意味軸で判定
隣接する2小節について (a)旋律到達点時刻 (b)低音機能 (c)内声の頂点と方向 (d)和声転換時刻 (e)休符／保持の分布を記録。意図した反復・回帰以外では少なくとも2軸を変える。3音セルの機械的複写や全体の単純移調だけでは発展と判定しない。回帰時は「保持した動機」「変形した和声／内声」「形式上の理由」を必須メタデータとする。
### 3. 非和声音は仮説→証拠→判定
各音に (voice, onset, duration, pitch, local_harmony, metric_accent, preparation, resolution) を持たせる。順次で両端の構造音をつなぐ音は `passing_candidate`、同じ音へ戻る順次隣接は `neighbor_candidate`。**候補は確定分類ではない**。和声区間とアクセント、実際の前後音、タイ／保持を照合したときのみ確定。倚音は強勢・解決、係留は準備→タイ保持→不協和→順次解決、先取音は次和声への先行と後続を別検査。解決の欠落や和声未確定なら `unknown`、PASS禁止。意図したテンションは `licensed_tension` として和声機能・配置・解決を別記する。
### 4. ユーザー好評作品との整合
『静かな期待』のフィードバックにある自然な機能和声、滑らかな3度・7度の内声、限定的な9th/13thを**別レイヤーの嗜好制約**として扱う。ショパンのm.21–28の4シャープを「意外な転調の推奨」と誤学習しない。低音の和声機能が不明な場合はテンション名を捏造しない。

## MusicXML／データ構造監査
- 6/8 = 四分音符3個分。 `divisions=960` なら2880tick。16分240、32分120、付点四分1440、付点二分2880。12個の16分で2880。連符は有理数で保持し、`time-modification` の actual/normal と表示上の連桁を別々に監査。
- staff/voiceごとに不変IDを割当て、`*^` 分岐と `*v` 合流で時間軸を追跡。`.` null token は新しい発音を意味しない。`ryy` 等の不可視休符も拍を消費。`backup` はカーソル移動であり追加の音価ではない。
- 同時和音は同一onsetの単一時間枠、タイは前音を保持、スラーは時間を消費しない。各声部の区間が小節を過不足なく満たすか検査し、意図しない重複・隙間をFAIL。混合連桁の編集注記がある場合はビームの忠実な復元を `UNVERIFIED`。
- 左右の各声部は同じ小節開始時刻を共有。ピッチが確定しない声部の完全5・8度並行、強拍の不協和、低音との濁りをPASSにしない。

## 実行テストと限界
Python `fractions.Fraction` をこの研究回で実行：
- PASS：16分12個 = 四分音符3個分（6/8）。
- PASS：16分6個 = 付点四分1個分。
- PASS：8分3個 = 付点四分1個分。
- PASS：独自の候補分類 `(60,61,62)→passing_candidate`、`(60,61,60)→neighbor_candidate`、`(60,64,67)→unknown`。これは**合成した音高の小規模ユニットテスト**であり原曲の非和声音を分類した結果ではない。
