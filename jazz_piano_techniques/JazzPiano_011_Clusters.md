## 2. 定義・機能
- `cluster` を「隣接する2度（半音または全音）を複数含む音群」と操作的に定義。単独の2度dyadは `cluster_seed`、3音以上の密集を `cluster` と分類する。音程ベクトルを実際のオクターブ配置で保持し、単に音高クラス集合が近いだけではclusterと認定しない。
- `chromatic` = 例 C–D♭–D [1,1]、`diatonic` = C–D–E [2,2]、`mixed` = E–F–G [1,2]。いずれも独自生成例で史料の引用ではない。
- 緊張の意味は「半音が多いほど常に強い」ではない。音域、強弱、長さ、旋律・ベースとの相互作用、前後の期待、フレーズ中の位置が決定する。音高クラスと和声機能を分離して保存。
- C7上の B♭–C–D = ♭7–1–9 は、低音Cの持続下でdominant-sus的な曖昧さを作り得るが、3度Eを含まないため単独では属機能を十分特定しない。E–F–G = 3–11–5 はE–Fの半音衝突を持ち、通常のC7の持続的な強拍和音では危険。Fを倚音としてEへ解決するか、susの機能に切り替える必要がある。
- Cmaj7上の B–C–D = maj7–1–9 は半音を含むが、B→Cの解決期待が常に必須とは限らない。機能的終止と色彩的持続を別の条件とする。

## 3. 声部進行・リズム・作品への接続
Feurzeigの《Blue Monk》分析では、長2度のモチーフがブルース進行のIVへ移調され、のちに半音音群へ拡張される。作曲上は `dyad_seed → register/scale-degree transposition → add_chromatic_neighbor → release` という**抽象化した独自規則**が可能。音群をランダムに散布せず、モチーフの同一性と和声進行の連結を保つ。移調はキーとベース機能の変化に応じて再綴りする。
リズムは強拍への恒常配置ではなく、フレーズの句読点、旋律の応答、裏拍の刺突、音価の伸縮と結びつける。休止や単音への縮退も音群密度の構造的な一部。Monkの具体的な拍位置・音価をこの初稿で推定しない。

## 4. 実装可能な作編曲生成規則 v1
入力: `{chord, key, melody_events, bass_events, phrase_boundaries, tension_curve, ensemble, registers, style, source_evidence}`。
1. 旋律・ベース・ガイドトーンを先に確定し、局所音群の役割 `accent|neighbor|suspension|color_hold` を選択。主旋律を上声で固定する場合はclusterが旋律を覆わない配置を優先。
2. 音群候補を `[1,1],[1,2],[2,1],[2,2]` の隣接半音幅から列挙。二音種はseedとして別管理。必要なら和音・モード内音に限定し、クロマチック近接音は解決目標を必須メタデータにする。
3. 実音域のレジスター、隣接音のスペクトル密度、声部の持続時間を別評価。低域での長い半音密集を強く減点し、高域の短いアクセントと同列に扱わない。
4. 次イベントへの各声の対応付けを最小移動だけで決めず、`guide_tone_resolution`、旋律の保持・倚音解決、フレーズ頂点、音群密度変化、休止を加重評価。非和声音は種類・準備・解決をイベント単位で記録。
5. ピアノ: 左手の3/7シェルや独立ベースと右手の短い密集を重ねる場合、低域過密と3/11衝突を監査。音群を同じリズムで延々と連打しない。
6. 弦6: Vn1旋律、Vn2/Vn3/Vaに二度密集を分配する際、実際の音域・音価・独立性を確認。Vc/Cbは機能的低音を保持し、密集の一部を無条件に低域へ割り振らない。Vn3は原則長めの音価とし、密集の全音符持続が強すぎる場合は発音時差・休止を使う。Cb不在時はVcへ低音を移すため密集の同時声数を減らす。
7. 監査出力: `{pitch_spelling, midi_notes, adjacent_intervals, degree_map, function, voice_leading, resolution_target, rhythm_role, register_risk, source_verified, unresolved}`。音程の整数検査だけで「音楽的に正しい」と判定しない。

## 5. 実行済み内部テストと限界
この実行でJavaScriptにより四種類の三音候補 `[60,61,62], [60,62,64], [64,65,67], [59,60,64]` を12半音移調し、隣接半音幅の保存を確認：**48/48 PASS**。これは移調時の音程算術のみ。最後の `[59,60,64]` は [1,4] で、上の二度密集候補集合には**該当しない負例**である。したがって48/48はcluster分類の成功率ではない。誤ってこれをclusterとして採用しないよう、分類器の別検査が必要。異名同音、楽器音域、音響、原譜照合、生成器の統合動作は未検証。

### 7.1 直接照合した研究資料と限界
David Feurzeig, “The Right Mistakes: Confronting the ‘Old Question’ of Thelonious Monk's Chops,” *Jazz Perspectives* 5/1 (2011), pp.29–59, 著者公開PDF https://www.uvm.edu/~dfeurzei/music/RightMistakes.pdf のpp.40–43（PDF p.12–15）とpp.46–48（PDF p.18–20）を直接閲覧。著者は「音色的 dissonance」（主音への近接鍵の打鍵、音色の拡張）と「構文的 dissonance」（和声的期待・声部進行に対する衝突）を区別しつつ、同一ジェスチャーが反復されモチーフになることで両者を横断し得ると論じる。**これは分析論文の直接照合であり、Monkの録音・映像・原譜そのものの直接照合ではない**。
同論文p.42脚注65のOslo《Blue Monk》分析は、第二コーラス終端のB♭–A♭（全音二音）、第三コーラスm.5のE♭–D♭と時折挟まるD、m.7のB♭–A–A♭（半音二個の三音群）、m.9のF–E♭と時折のEを区別する。二音を「三音cluster」と誤記しない。著者自身が映像の一部の運指を不鮮明とするため、音符・打鍵時刻の確定的な一次観察としない。
同論文pp.42–43では、短二度の並進による《These Foolish Things》の例と、二重半音セル（pitch-class set class 012）を持つMonkの和音の反復・終止的使用を紹介。短二度の存在は必ずしも「次の拍で解決必須」を意味しない。和音の最終目的音としての不協和もスタイルに依存して成立する。これはFeurzeigがKurzdorferやTuckerを引用して述べる二次分析で、原譜照合済みと混同しない。

### 7.2 作曲原理：二層の役割と時間
音群を単に音高集合として扱わず、(A)音色的厚みを担うneighbor/split-note、(B)モチーフとして再帰する構造的cell、(C)独立した和声の3度・7度と衝突するsuspension、の三つの役割タグで管理する。同一音群に複数タグ可。衝突を評価する際、局所的な[1,1]の音程だけでなく、低音のコード機能・主旋律・反復頻度・和声リズム・解決目標・発音時間差を検査する。

独自の生成例（Monk採譜ではない）：B♭ bluesのI上でB♭4–A♭4（♭7–1）を動機種として置き、IV=E♭7でE♭5–D♭5へ平行移動する。次にE♭5–D5–D♭5を挿入し、Iへ戻る時はB♭4–A4–A♭4に縮約する。これはFeurzeigの記述に着想した**抽象モデル**であり、各音域・音価・小節位置を録音に帰属しない。AはB♭に対する長7度のクロマチック近接音であり、通常のI7の安定構成音ではない。持続の可否はブルース語法と終止位置で決定する。

別の独自例：F7のガイドA(3)と上声B♭(11)を同時保持すると短9度（A3→B♭4なら13半音）が生じる。これは単に[1,1] clusterの分類ではなく、**離れたレジスター間の和声的衝突**である。B♭→Aを時間的に解決する標準経路と、B♭を再打鍵し意図的に解決を遅らせる構文的例外を区別する。Feurzeigが《'Round Midnight》m.15/17/19で記述する比較はこの後者の文脈に関連するが、本例の音域・イベント列は自作。

### 7.3 アルゴリズムv2
入力は既存v1に加え `structural_note_ids, neighbor_ids, motive_id, density_envelope, harmonic_collision_pairs, onset_offset, release_offset, role_tags` を保持。
1. まず低音・主旋律・ガイドトーンを固定し、二度種（半音/全音）と音群の**実音高順**を決める。三音以上かつ隣接実音程が各1または2半音の場合のみ操作的clusterに分類。単独二度はseed、重複ユニゾン・三度以上の隙間を含むものは除外。
2. seedから転位、クロマチック挿入、縮退、休止、リズム拡大縮小を行う。動機の変形は元の声部輪郭・和声機能との関係を保持し、任意の不協和音の連発にしない。
3. `timbre_neighbor` は発音時間の短さ・強弱・音域で評価。`syntactic_collision` は3/11、maj7/♭7、長短9度などの**機能的矛盾**と反復・解決延期を別評価。全ての短二度を無条件に悪いとみなさない。
4. 句の緊張曲線は音群密度、強弱、アタック回数、休止、音域、和声的衝突を別のパラメータとする。Feurzeigのいう平均的なdissonance densityは実測の数値閾値ではなく、相対的な制御概念として採用。
5. ピアノはベース奏者の有無とLHシェルの占有音域を確認し、RHの近接音を高域短音価または中域モチーフに配置。弦6はVn1旋律、Vn2/Vn3/Vaの上声近接を基本候補とし、Vc/Cbの低域に半音音群を機械的に押し込まない。弦の持続音ではピアノの短い打鍵と音響が異なるため、解決時間・音量の再設計を要する。
6. 出力時に`source_evidence_level`を各主張に紐付け、録音未照合の事例を`secondary_analysis`、自作の生成例を`constructed`とする。
