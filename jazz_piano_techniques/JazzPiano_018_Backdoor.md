# Jazz Piano 018 — Backdoor cadence (ivm7–♭VII7–I)
研究日 2026-11-23 / 累計 **1/3** / 判定 **暫定（一次譜面・録音逐音照合未達）**

## 1. 範囲・既存研究との境界
GitHubの既存ディレクトリを取得し018同名マスターが存在しないことを確認。016 Tritone Substitution と017 Passing Diminished の現行本文を読んだ。016は♭II7→I（subV）、本稿は♭VII7→I（backdoor）であり、**根音もガイドトーンの同一性も違う**。017のdim経過と同じく「到達先・拍節・綴りで機能を確定」する。ユーザー高評価編曲の原ファイルとの照合は未実施。

## 2. 音度・和声機能
長調Iの主音をtとする。ivm7根音=t+5、♭VII7根音=t+10（mod12）、I=t。C調は Fm7(F,A♭,C,E♭) → B♭7(B♭,D,F,A♭) → Cmaj7(C,E,G,B)。
Fm7→B♭7はE♭→D（-1）、F/A♭の共通音（必要なら保持）、C→B♭（-2）等が可能。B♭7→Cmaj7はA♭→G（-1）、D→E（+2）またはD→C（-2）、F→E（-1）、B♭→B（+1）またはC（+2）。**唯一の義務的解決ではない**。特にB♭7の3度DはC調の導音Bではなく、通常G7(B,F)の3度/7度とB♭7(D,A♭)は一致しない。♭VII7を「トライトーン代理」と同一視しない。
Fm7–B♭7はE♭長調のii–Vにもなる。着地がE♭なら通常のii–V–I、Cならバックドアとして聴ける。局所的なiv借用、短調下属のプラガル色彩、代替終止という説明は互いに排他的でないが、**すべての♭VII7が機能的終止ではない**。
ivm6(F,A♭,C,D)とB♭9(B♭,D,F,A♭,C)は上4音の集合が同一。B♭を低音に加える操作は構造的な橋渡しになり得る。ただしFm7（E♭を含む）とFm6を同一視しない。

## 3. ピアノ配置・リズム・旋律
ベース奏者あり：LHは Fm7のA♭/E♭ → B♭7のD/A♭ → Cmaj7のE/B等を候補とし、RHの旋律音・テンションと音域の重複を評価。ベース奏者なし：根音を別イベントとして供給するか、省略理由を記録。B♭7(#11)のEはCmaj7の3度として保続可能だが、#11の許可を「常に最適」としない。
拍節は「ivを強拍、♭VII7を次の弱拍、Iを次の強拍」とする短縮型と、各和音が1小節以上の拡張型を別候補とする。固定旋律B（Cmaj7の長7度）をB♭7上で長く鳴らすと根音との短2度（異オクターブなら長7度）摩擦が生じ得るため、音域・持続・解決を検査する。リズムの採用は曲の句読点・旋律到達拍を優先する。

## 4. 独立設計例（歴史的採譜ではない）
C: Fm7→B♭7→Cmaj7; F: B♭m7→E♭7→Fmaj7; E♭: A♭m7→D♭7→E♭maj7。
Cの4声ガイド例：Fm7 [F3,A♭3,C4,E♭4] → B♭7 [F3,A♭3,B♭3,D4] → Cmaj7 [E3,G3,B3,C4]。音の順番を同一voice_idとみなして自動的に接続してはならず、最小移動・声部交差・各音域を別途最適化する。Cmaj7に到達しても全声部が必ず半音解決するわけではない。

## 7. 誤用・負例
- B♭7→E♭maj7をC調のバックドア終止と自動ラベルしない（通常V/♭IIIの可能性）。
- G7→CとB♭7→Cはガイドトーン集合が違う。016のsubV検証ロジックを再利用しない。
- Fm7とFm6、B♭7とB♭9を無条件に同一視しない。
- 旋律BがB♭低音と同時発音しても全音域で一律禁止しない。発音時間・配置・解決を評価。
- 単純なコード列だけから演奏者固有のボイシングや歴史的録音を帰属しない。

### 9.2 声部進行の厳密化
Cの Fm7=[F,A♭,C,E♭], B♭7=[B♭,D,F,A♭], Cmaj7=[C,E,G,B]。
- 前半は F/A♭を共通音として保持し、E♭→D（半音下降）、C→B♭（全音下降）が可能。
- 後半は A♭→G（半音下降）、F→E（半音下降）、D→E（全音上行）またはC（全音下降）、B♭→B（半音上行）またはC（全音上行）。**B♭7のD→Cを半音とは書かない**。
- B♭7のガイドトーン D–A♭とG7の B–Fは異なる。B♭7はG7のトライトーン代理ではない。♭VII7→Iの低音は全音上行で、♭II7→Iの半音下降とも異なる。
- Fm6上部4音 F,A♭,C,D = B♭9の3,5,7,9（転回順序は別）。一方Fm7はE♭を含み、この集合同一性は成立しない。
- B♭7(#11)のEをCmaj7の3度に係留する場合、B♭7の構成音D,A♭との近接、旋律の発音長、解決先を別々に採点する。テンションを無条件許容しない。

### 9.3 12調・負例の限定計算
実装のためのpitch-class検査を下記のように定義する（音名綴りは別モジュール）。
`t=0..11; iv=[t+5,t+8,t,t+3]; bVII7=[t+10,t+2,t+5,t+8]; Imaj7=[t,t+4,t+7,t+11] (mod12)`。
全12調で (i) iv∩bVII7 は2音 {t+5,t+8}、(ii) bVII7の♭7→Iの5度は半音下降、(iii) bVII7根音→I根音は全音上行、(iv) bVII7の3度とV7の3度/7度は一致しない、を検査対象とする。
**検査の射程はpitch classに限る**。異名同音綴り、実際のレジスター、旋律イベント時間、並行完全音程、楽器奏法は別問題。
負例：Fm7–B♭7→E♭maj7はE♭へのii–V–Iであり、Cへのバックドアとして数えない。Fm7–B♭7→Cmは短調の帰着で、長調Imaj7の生成規則を無条件適用しない。B♭7→C7は主和音到達ではなく次の属七への接続の可能性を残す。

### 9.4 時間付き生成規則v2
1. 到達候補の構造ラベルを先に確定：Imaj7/I6/Im/♭III/V of ♭III/一時転調。機能は和音名だけから決めない。
2. 強拍の旋律音を固定し、音度綴り・持続・非和声音の解決期限を付す。到達直前の最後の和音に必要な長さを確保し、機械的な1拍ごとの置換を避ける。
3. LH/RHまたはVn1/Vn2/Vn3/Va/Vc/Cbにvoice_idを割り当て、音域・音価・休符を含む候補イベントを生成。和音の配列順を声部識別子にしない。
4. 同時発音は区間交差 `max(startA,startB)<min(endA,endB)` で検出。特に低域短2度、旋律長7度と伴奏根音の衝突、係留の解決不在をタグ付けする。音響的に常に悪いと断定せず、音域・拍・ダイナミクス・意図を判定材料とする。
5. 共通音保持、半音解決、独立した内声、旋律の句読点、ベースの到達方向を多目的評価。声部交差・不可能音域・無意図の重複は罰点。意図した並行ブロックコードは例外タグを要求。
6. 弦6では持続音の実際の時間重なりを重視し、Cbの省略やセクション休止も選択肢にする。ピアノではLHの3度/7度シェルとRHの旋律・テンションを別イベントとして監査。
7. 候補の品質が基準未満なら元の進行を維持し、採用理由と拒否理由をログに残す。
