## ■ 今回のテーマ：シェル・ボイシング
### 1. 本質と音楽的役割
3rdと7thはコードの質と機能を決定するガイドトーン。ルートと組み合わせた2〜3音のシェルが、伴奏の骨格を作る。スウィングは和音そのものではなくタイミング、アーティキュレーション、アクセントから生じる。シェルは和声の進行方向を聴き取りやすくする。

### 2. 音の並びと構造のルール
Key C の ii–V–I:
- Dm7 = D F A C: 3rd=F, 7th=C
- G7 = G B D F: 3rd=B, 7th=F
- Cmaj7 = C E G B: 3rd=E, 7th=B
- 2声の理想的連結（下声/上声）: F3/C4 → F3/B3 → E3/B3。C4→B3（半音）、F3共通→E3（半音）。全声部が半音または保持。
- ベーシストがいる場合はルートを省略して右手にガイドトーンを置く。独奏では左手低音でルートを支える。

### 3. 具体的な実践例
**基本形（左手ルート／右手シェル、低音順）**
- Dm7: LH D2 / RH F3–C4
- G7: LH G2 / RH F3–B3
- Cmaj7: LH C2 / RH E3–B3
**5音の拡張形（低音順）**
- Dm9: LH D2–C3 / RH F3–A3–E4
- G13(9): LH G2–F3 / RH B3–E4–A4
- Cmaj9: LH C2–B2 / RH E3–G3–D4
拡張形では音域の飛躍が増えるため、基本シェルの声部連結とは別に扱う。E4はG13の13th、A4は9th。右手の位置は演奏時に再配置可能。

### 4. よくある間違い
- 毎コードをルートポジションで平行移動し、3rd/7thの半音解決を失う。
- 3rdと7thを省いてテンションばかり重ね、機能を曖昧にする。
- 低音域に密集配置して濁らせる。
- 音を重ねるだけでスウィングすると誤解する。

### 5. 5分間実践ドリル
1分: 右手 F3–C4 → F3–B3 → E3–B3 を反復。
1分: 上声C4→B3→B3、下声F3→F3→E3を歌う。
1分: LH D2→G2→C2を追加。
1分: 9th/13thを足し、ガイドトーンを失わずに配置。
1分: ♩=80で2拍と4拍に短くコンピング、タイミングと音価を比較。

## 作編曲への有機的な転用
- ピアノ独奏: LHはルートと必要に応じ7th、RHは3rd・7thと旋律のテンション。低音で密集させない。
- 弦楽6声: Cb/Vcがルート、Vaが3rd/7th、Vn2がもう一方のガイドトーン、Vn1が旋律。Vn3は長い共通音。CbなしでもVcで機能成立。
- MusicXML監査: コードの3rd・7thを特定し、ii–V–Iで半音解決と共通音保持を検査。禁則（平行5/8）と意図的なジャズ平行の区別。
- 応用優先順位: まず2声の自然な連結、次にルート、最後に9/11/13。コードの見た目の複雑さを品質と混同しない。

### 音度と同定可能性
七の和音の核を3rdと7thとする。ただし「3rdと7thだけで和音が一意に決まる」という強い命題は誤り。例えば C7 の E–B♭ と G♭7 の B♭–F♭（実音E–B♭）は同一pitch-class対を持ち、根音・ベース・進行先で裏コード関係を判定する。C7 と Cmaj7 は root+3rd の C–E を共有し、Cm7 と C7 は root+♭7 の C–B♭ を共有する。さらに Cm7 と Cm7♭5 は root+♭3+♭7 でも区別できず、♭5の要否は旋律・ベース・機能に依存する。したがって「省略可能な音」は和声文脈に対する条件付き判断である。

C調の Dm7→G7→Cmaj7：F3–C4 → F3–B3 → E3–B3。voice_idを下声/上声に固定すると移動は [0,-1]、[-1,0] 半音。iiの7th C→Vの3rd B、Vの7th F→Iの3rd Eという半音解決と、iiの3rd F→Vの7th F、Vの3rd B→Iの7th Bという共通音保持を分離して記録する。根音D→G→Cの完全4度/完全5度運動は別声部であり、上声の半音移動を根音運動と混同しない。F調では Gm7(B♭,F)→C7(B♭,E)→Fmaj7(A,E)、B♭調では Cm7(E♭,B♭)→F7(E♭,A)→B♭maj7(D,A)。括弧内は各和音の3rd/7thを音名順で示し、実配置の上下順を固定しない。異調は手計算であり、12調の自動検査ではない。

### 和声・拍節・旋律の生成規則 v2
入力：chord_function、root、quality、bass_event、melody_events(onset,offset,pitch,role)、phrase_goal、ensemble、voice_ranges。
1. 根音を含むR+3+7、R+3、R+7、根音なし3+7を候補として列挙。R+3やR+7で不足する和音品質は別パート/前後文脈から確定できる場合に限る。m7♭5、alt、sus、無3度和音は追加制約を要求。
2. 到達和音の3rd/7thと旋律を先に固定。隣接和音の3rd/7thをvoice_idで追跡し、共通音・半音解決・順次移動・必要な跳躍を候補化。最小移動だけでなくフレーズ終止の解決を優先。
3. 強拍の長い旋律音にシェル構成音との摩擦がある場合、係留・倚音・意図的なテンションかを分類し、解決先と期限を付与。単にpitch-class集合に含まれないという理由で自動棄却しない。
4. 時間軸は半開区間 [onset,offset) で扱い、別声部の同時持続のみを縦の摩擦として検査。リズムは和声の発音・保持・休止・先取りを独立イベント化し、全コードを毎拍再打鍵することを禁止するわけではないが既定動作にしない。
5. ピアノはベース奏者ありなら3+7を中域で、独奏ならR+3+7またはR+3/R+7を低域の濁りに応じて選択。弦6声ではCb/Vcの根音とVa/Vn2の3rd/7thを分担し、Vn1の旋律を固定、Vn3を無条件の重複で埋めず対旋律/休止/係留に使用。Cbのオクターブ移調とVcとの重複を監査。
6. 採否は構造的到達、旋律整合、声部連続、ベースの機能、時間的摩擦、音域、密度の順に評価。3rd/7thを保持しても旋律や機能に不適合なら別配置へ戻す。

### 独立設計の負例
- C7のR+3=C–EのみからCmaj7との区別を断定する候補は棄却。
- Cm7♭5をC–E♭–B♭のみで「♭5まで明示済み」と認定する候補は棄却。
- E4 [0,1) と E♭5 [1,2) は同時衝突しない。一方 E4 [0,3) と E♭5 [1,2) は実音程長7度の同時摩擦。後者も禁則として一律棄却せず、声部役割・音域・解決を審査する。
- 裏コードで同一ガイドトーン集合が現れても、根音と到達先を変えずに機能転換したと主張しない。

### 原理と音度
C majorのii–V–Iでは、Dm7の3rd F/7th C → G7の7th F/3rd B → Cmaj7の3rd E/7th B。低声F3→F3→E3、上声C4→B3→B3という**声部IDを保った**経路は各遷移で[保持,半音下降]→[半音下降,保持]。これは特定の転回形の構成例であり、すべての和声・すべての演奏に強制する規則ではない。ベースD→G→Cが根音を明示しない場合、シェル単独では裏コード・同音集合などの機能曖昧性が残る。根音なしの音響集合だけから機能を断定しない。

### 拍節・対位法・生成規則v3
入力は chord_function、harmonic_rhythm、bass(onset,offset,pitch)、melody(onset,offset,pitch,role)、phrase_target、instrument_ranges、density_budget。各和声区間について3rd/7thの音高集合と実際のレジスター候補を作る。**候補の順位付け**は(1)終止・フレーズ機能、(2)旋律と同時持続音の許容可能な摩擦、(3)声部IDを追った共通音・半音解決、(4)音域と低域密集、(5)アタック密度と先取り・休止の形、の順とする。拍節は和声切替点と発音点を区別し、先取りの和音が旧旋律に重なる場合は非和声音の役割・解決期限を別途評価する。完全5度/8度の連続は独立した声部の実音域で検査し、ジャズの意図的な平行ブロックと機械的な禁則を混同しない。

ピアノ：独奏時はベース機能をLHに配し、中声の3rd/7thと旋律をRHまたは両手で分担する。ベース奏者との共演ではLHのルートを省略できるが必須ではない。弦楽6声：Vn1旋律、Vn2/Vaにガイドトーン、Vc/Cbにベース機能、残り1声を対旋律・テンション・係留または休止に配分する。実音域・Cb記譜音とのオクターブ差・持続音衝突を別々に監査する。ユーザーの高評価4声作品 Feedback_002 では終止への推進とソプラノの弧、テンションの局所的な解決が重要であり、単なる最小移動は十分条件ではない。
