## 2. 和声原理：横方向の一声が縦方向の和音名を変える
C minorの固定核C–E♭–Gの上で上方の可動声を C5→B4→B♭4→A4 とする。各段階の可動声の根音基準度数は1→maj7→♭7→6、音程差は-1,-1,-1半音。コード表記はCm→Cm(maj7)→Cm7→Cm6。ただし初段のCは根音重複で、後段のBはC和声における導音的緊張、B♭は自然短音階の♭7、Aはドリアン的/旋律短音階的6として解釈可能。これらは**4つの独立した機能転調**ではなく、固定短三和音に対する連続的色彩の変化としてまず解析する。Aを長く保持する際のCm6はC–E♭–G–Aであり、A–C–E♭–G（Am7♭5の転回形）との同音集合性だけで根音をAへ自動変更しない。低音・旋律・前後の終止が根音認知を決める。

別案：同じC→B→B♭→Aをベースに置き、上声C–E♭–Gを保持する場合はCm/C→Cm/B→Cm/B♭→Cm/A。**上声クリシェと低音クリシェは音高集合が似ても音響・和声機能が異なる**。低音Bと上声Cの短9度（実音のオクターブ配置次第）、低音Aと上声B♭の短9度、低音の独立した半音線の可聴性を個別に審査。ベースが和声根音を再定義するなら、単なる「Cmが続く」との分析を見直す。

## 3. リズム・対位法・フレーズ
- 4段階を機械的に4小節へ割り当てず、旋律の句読点、持続、休符、ベースの方向、到達先に合わせて例えば2+1+1拍、4+2+1+1拍、1小節ごとの4段階を候補とする。後半の密度加速は終止への期待を高めうるが、常用しない。
- 固定旋律の長音と可動声を対比し、同時に全声を半音で動かさない。旋律がB♭を長く保続する時、可動声Bとの短2度/短9度の衝突を発音重なりで評価。対位法上の「旋律と反行」よりも、必要な係留/倚音解決と可動声の独立性を優先する場合がある。
- 固定核を完全に固定する必要はない。声部交差・音域・長い旋律フレーズに対応するため、構造音のオクターブ変更や間引きを許すが、クリシェの同一voice_idと連続性を保存。
- 最後の6(A)を次のDm7♭5のA♭へ半音下降、さらにG7のGへ下降させる拡張は候補。ただしDm7♭5/A♭の低音とG7の機能を別々に検証し、クリシェの継続とコード代理を混同しない。

## 4. 異なるキーの理論例（独自作例・採譜ではない）
- C minor: C–B–B♭–A (1–maj7–♭7–6)
- F minor: F–E–E♭–D
- B♭ minor: B♭–A–A♭–G
- E minor: E–D♯–D–C♯
各例の固定核は根音・短3度・完全5度。異名同音を単なるMIDI pitch classから逆算せず、綴りと度数を別保存する。B♭ minorのGは長6度であってG♭ではない。

### 9.2 機能を保持するモデルと代替解釈
固定核C–E♭–G、可動声C5–B4–B♭4–A4では、低音Cが保持される限り、上部の半音線はトニック・マイナーの色彩変化として聴取できる。各音は根音重複→長7→短7→長6。Cm(maj7)のBは上行導音の古典的解決を要求するとは限らず、線全体の下降方向の中でB♭へ移る。Cm6のAは自然短音階のA♭と区別し、旋律短音階上行形/ドリアンの長6度という音集合上の関係と、実際の調性感を混同しない。

低音がC→B→B♭→Aへ移る場合、和音核C–E♭–Gを保持しても、根音認知は変わりうる。とくに最終A–C–E♭–GはAm7♭5と同音集合なので、後続D7→GmならAを局所根音とみなす解析も候補となる。一方C minorへ戻るならCm6/Aという保続核解釈を残す。**pitch-class集合だけで和音機能を決定しない**。ベースの継続、強拍、旋律着地点、後続の機能和声を加えた複数仮説を保持する。

### 9.3 拍節・音価・対位法の設計
各段階を1小節全音符に置くと線の認知が明瞭だが、毎回同じ長さでは機械的になる。可動声の到達が主旋律の休止や長音に応答する配置と、旋律と同時に動く配置を別候補として評価する。ピアノでは打鍵後の減衰により持続区間の音響実態が異なり、弦楽6声では保持した核と可動声が全音価で重なるため、低音BとCの短9度、あるいは隣接声部の半音摩擦の継続時間を明示的に計測する。古典的な平行完全音程の機械的全禁止ではなく、構造声部・様式・露出度・意図的な平行を区別する。

### 9.4 生成アルゴリズムv2：和声仮説と時間的衝突

### 10.2 音度・機能・声部の反証可能なモデル
C minorの構造核 C–E♭–G と可動声 C5→B4→B♭4→A4 は根音重複→長7→短7→長6、下降半音3回。前半のC–B–B♭は単一調中心での色彩変化であり、必ずしも個別のドミナント機能を要求しない。A4はCm6の長6度であり、A♭に置き換えたCm(♭6)とは区別する。低音をCに保持する場合の和声仮説は tonic-minor prolongation、低音をC→B→B♭→Aへ動かす場合は inversion/linear-bass と re-rooting を競合させる。最後のA–C–E♭–GはAm7♭5と同じpitch-class集合だが、ベースAと後続D7→Gmの有無で根音仮説を再評価。固定核の声部IDが保存されることは「機能が固定」という意味ではない。
反例: C–B–B♭–Aの線があっても、各拍のベースと3/7が独立に転調・終止を作る場合は単純なtonic-minor clichéと呼ばない。BとCが低域で同時に鳴る際の短9度は、音高距離・配置・実際の発音重複を確認して判断。異名同音BとC♭をpitch classだけで同一機能として扱わない。

### 10.3 拍節・旋律・対位法の生成規則v3
各イベントを (voice_id,pitch,spelling,degree,onset,offset,bass_hypothesis,harmony_id,source_status) として保持。固定旋律と低音の着地点を先に確定し、可動声の3〜5段階の線を選択。音価はフレーズの息継ぎと旋律の長音に合わせ、たとえば4+4+2+2拍と2+2+1+1拍を別候補として比較。前半を伸ばし後半を圧縮するのは終止接近の一手段であり、毎回の定型にしない。コード記号は各イベントのベース・ガイドトーン・持続声・次の解決から**後で**再推定する。
硬制約：既存旋律の音高/拍、voice_idの連続性、楽器音域、解決期限、声部の同時発音可能数。軟制約：低域での長い半音摩擦、無目的な半音線の重複、旋律とのリズム補完、動機の方向、和声機能の明瞭さ。候補ごとに(a) tonal prolongation、(b) linear bass/inversion、(c) functional re-rootingを採点し、どの仮説も閾値未満ならクリシェ採用を拒否する。声部交差、構造的平行完全音程、持続不協和は意図タグを付して別監査。
ピアノ：LHでガイドトーンを残し、RHの主旋律の下に動く線を置く場合は音域と減衰・ペダル重複を評価。弦6：Vn1主旋律、Vn2/Vaの一方に可動声、他方に核、Vn3は低密度支持、Vc低音/対旋律、Cb任意の根音。Cb不在ならVcの低音を優先し、Vaに内声を再配分。弦の長音による隣接半音の露出はピアノの減衰と同一視しない。これは**設計仕様であり統合生成器は未実装**。
