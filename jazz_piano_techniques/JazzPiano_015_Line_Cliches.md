## 2. 和声原理：横方向の一声が縦方向の和音名を変える
C minorの固定核C–E♭–Gの上で上方の可動声を C5→B4→B♭4→A4 とする。各段階の可動声の根音基準度数は1→maj7→♭7→6、音程差は-1,-1,-1半音。コード表記はCm→Cm(maj7)→Cm7→Cm6。ただし初段のCは根音重複で、後段のBはC和声における導音的緊張、B♭は自然短音階の♭7、Aはドリアン的/旋律短音階的6として解釈可能。これらは**4つの独立した機能転調**ではなく、固定短三和音に対する連続的色彩の変化としてまず解析する。Aを長く保持する際のCm6はC–E♭–G–Aであり、A–C–E♭–G（Am7♭5の転回形）との同音集合性だけで根音をAへ自動変更しない。低音・旋律・前後の終止が根音認知を決める。

別案：同じC→B→B♭→Aをベースに置き、上声C–E♭–Gを保持する場合はCm/C→Cm/B→Cm/B♭→Cm/A。**上声クリシェと低音クリシェは音高集合が似ても音響・和声機能が異なる**。低音Bと上声Cの短9度（実音のオクターブ配置次第）、低音Aと上声B♭の短9度、低音の独立した半音線の可聴性を個別に審査。ベースが和声根音を再定義するなら、単なる「Cmが続く」との分析を見直す。

## 3. リズム・対位法・フレーズ
- 4段階を機械的に4小節へ割り当てず、旋律の句読点、持続、休符、ベースの方向、到達先に合わせて例えば2+1+1拍、4+2+1+1拍、1小節ごとの4段階を候補とする。後半の密度加速は終止への期待を高めうるが、常用しない。
- 固定旋律の長音と可動声を対比し、同時に全声を半音で動かさない。旋律がB♭を長く保続する時、可動声Bとの短2度/短9度の衝突を発音重なりで評価。対位法上の「旋律と反行」よりも、必要な係留/倚音解決と可動声の独立性を優先する場合がある。
- 固定核を完全に固定する必要はない。声部交差・音域・長い旋律フレーズに対応するため、構造音のオクターブ変更や間引きを許すが、クリシェの同一voice_idと連続性を保存。
- 最後の6(A)を次のDm7♭5のA♭へ半音下降、さらにG7のGへ下降させる拡張は候補。ただしDm7♭5/A♭の低音とG7の機能を別々に検証し、クリシェの継続とコード代理を混同しない。

## 4. 異なるキーの理論例（独自作例・採譜ではない）
- C minor: C–B–B♭–A (1–maj7–♭7–6)
- F minor: F–E–E♭–D
- B♭ minor: B♭–A–A♭–G
- E minor: E–D♯–D–C♯
各例の固定核は根音・短3度・完全5度。異名同音を単なるMIDI pitch classから逆算せず、綴りと度数を別保存する。B♭ minorのGは長6度であってG♭ではない。

## 5. 実装可能な生成規則 v1（統合生成器未実装）
入力: tonal_center, chord_quality, harmony_span, fixed_melody, bass_events, moving_voice_id, target_degree, available_registers, phrase_goal, rhythmic_density, instrument, intentional_dissonance_tags。
1. 固定和声核を決め、クリシェ候補の方向（下降/上昇）、度数列、到達音、和声内かベースかを選択。候補の最小長は3イベント、局所隣接音の戻りと区別する。
2. 可動声の音高・音名・degree・onset・offset・voice_idを一貫して保持。和音ラベルは各イベントのベース/核/可動声から再導出する。和音ラベルを先に列挙して声部IDを失わない。
3. 硬制約: 固定旋律、イベント時刻/拍数、実音域、解決先、声部ID、Cb有無。軟制約: 和声認知の持続、半音衝突の長さ、旋律との反行、フレーズ密度、不要な低音混濁、到達後の停滞。
4. 2〜8小節の時間窓で動的計画法/beam search。候補別に拒否理由と各費用を保持。反復する度数列を無条件で量産せず、旋律・リズム・終止への機能で選択。
5. ピアノは可動声の手割り、減衰、低音独立性を監査。弦6はVn1主旋律、Vn2/Violaの可動声、Vn3の低密度支持、Vc低音/オブリガート、Cb任意の基礎低音を初期配置とし、Cb不在時はVcの低音機能を優先して再最適化。持続する弦の半音摩擦はピアノの短い打鍵より長く露出する。
6. 生成後、同一voice_idの単調性、可動声と固定核の関係、異名同音、強拍衝突、旋律保持、終止先、意図的例外を監査する。

## 7. 誤用・例外・批判的自己監査
- クリシェを「dim経過和音の連鎖」と一律に命名しない。和声根音が固定ならまず固定核+可動声で解析。
- B→B♭の半音下降を導音B→Cの古典的解決と誤認しない。Bは下降することで別の色彩へ移る。
- Cm6のAをA♭と混同しない。Cm(♭6)は異なる和音集合と機能を持つ。
- 弦で可動声を保続して隣接半音が衝突する場合、音価短縮/配置変更/意図的摩擦の明示を検討。
- 作品の流通コード例を原譜や特定演奏の逐音実証とみなさない。とくに同曲の版違いに注意。
- 013/014の既存研究を引用しても、ユーザーが高評価した実際の編曲成果物と照合したことにはならない。
