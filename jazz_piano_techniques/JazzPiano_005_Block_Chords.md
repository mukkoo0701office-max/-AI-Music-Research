# Jazz Piano 005 — Block chords / Locked-hands harmonization
研究日：2026-11-21｜**第1回/最大3回**｜優先：コード・ボイシング・アプローチ・声部進行

## 研究課題と根拠の区別
ブロックコードは旋律の各音に和声を付け、旋律と内声のリズムを同期させるテクスチャー。特にGeorge Shearingに関連づけられるlocked-handsでは、旋律をトップに置いた4声と、その旋律をオクターブ下で補強する5声配置がよく説明される。Red GarlandのブロックコードやMilt Bucknerの用法は同一の固定アルゴリズムとみなさない。

参考：
- George Shearingの演奏様式の概説：https://www.britannica.com/biography/George-Shearing
- Barry Nettles & Richard Graf, *The Chord Scale Theory & Jazz Harmony*：https://djvu.online/file/betNTplepgXqK （4-way closeとapproachの理論枠組み）
- ジャズの和声化を計算処理する論文： https://www.jstage.jst.go.jp/article/ast/29/1/29_1_51/_pdf

**資料限界**：今回は原録音の直接採譜や上記文献の譜例の実音照合を実施していない。以下は歴史的奏者の実演譜ではなく、独自に構成した理論・生成モデル。

## 1. テクスチャーの核：旋律トップと同期する内声
- 入力：旋律 pitch・onset・duration、コード記号、ベース、目標声部数。
- 出力：トップの旋律音を変えずに4声（必要に応じて旋律オクターブ重複で5声）を生成。
- 原則：和音を全て同じ長さで塗りつぶすのではなく、**旋律の音価に同期**する。密度が高すぎる箇所はブロックを間引く。
- テンションは旋律が9/11/13のときに内声の3/7を失わないよう、5度・根音の省略／置換を検討。**すべての旋律音が元のコードトーンとは限らない**。

## 2. アプローチの3系統を分離する
### Chromatic parallel approach
Cmaj7のトップB4を含むclose配置 C4–E4–G4–B4 [60,64,67,71] に対し、半音下のアプローチ和音 B3–E♭4–F♯4–B♭4 [59,63,66,70]。各声部が+1半音でCmaj7へ解決。これは**Cmaj7に属するダイアトニック和音ではなく、目標へ到達するための経過的な和音**。

### Diminished approach
Bdim7 = B3–D4–F4–A♭4 [59,62,65,68] はG7(♭9)の根音を省略した構造。Cmaj7への解決では、B→C、F→Eなどの機能的な半音解決を別途割り当てる必要がある。**4声の単純な順位対応だけでは全声部が半音解決するとは限らない**。

### Diatonic passing harmony
コードスケールに基づく経過的和音。例：C major上で旋律E4→F4→G4のとき、F4の内声を自動的にCmaj7の全音平行移動で作るのではなく、Fの和声的役割（11thの係留、IVへの一時的変化など）と強拍／弱拍を評価する。

## 3. コードの色彩と対位法を別々に評価
- 縦の評価：3rd・7thの機能、旋律との衝突、低音域の濁り、意図した9/11/13の存在。
- 横の評価：各声部の跳躍、半音解決、係留、目標音への到達、平行5/8度。
- 時間の評価：アプローチが弱拍から強拍へ解決するか、連続ブロックがフレーズの推進力を損なわないか。
- **禁止すべき単純化**：全ての旋律音に同じコード形を機械的に転調すること、dim7を使えば必ず滑らかになるとすること、旋律を犠牲にして内声の最小移動を優先すること。

## 4. Pythonによる最小構造検査
Cmaj7 close = (60,64,67,71)。半音下approach=(59,63,66,70)。両者の差は(+1,+1,+1,+1)。Bdim7=(59,62,65,68)はpitch-class集合{11,2,5,8}。この3種類の構成音と解決方向を実行検査。**和音の適否、歴史的真正性、旋律の表現力を検証するものではない**。

## 5. 弦楽6声への転用
- Vn1：旋律。Vn2/Vn3/Va：和声内声。Vc：低音または第4声。Cb：根音を必要時に補強し、**常に全音符で埋めない**。
- Vn3は原則として音価の長い、演奏難度の低い声部に留め、ピアノの全てのブロック打鍵をそのまま移植しない。
- 旋律が8分・16分で動く場合、ブロックコードを全打鍵で同期させるより、フレーズの頂点・解決・和声の転換点だけに配置する選択を持つ。
- 弦の持続音・タイ・倚音・内声の半音下降（6→♭6→5）を利用し、ピアノ的な垂直同時発音を弦楽的なグラデーションに変換。

# 第2回/最大3回：8小節のC6–dim7ブロック・ハーモナイゼーション
研究日：2026-11-21。**累計2/3**。今回は実際にPythonを実行した。

## 典拠と設計の区別
Mark Levine, *The Jazz Piano Book*, Chapter 19（https://moodle.cegepsherbrooke.qc.ca/pluginfile.php/108871/mod_folder/content/0/Jazz%20Piano%20Book%20By%20Mark%20Levine.pdf?forcedownload=1）では、C6の和声音 C/E/G/A をC6の転回形で、経過的な D/F/G♯/B を同一dim7集合の転回形で和声化する原理が説明される。これを**C6–dim7の8音集合**として検査した。Shearing式locked handsは4-way closeの旋律を下オクターブで重複する構造である（Grove Music, https://docdrop.org/pdf/Strunk---2021---Jazz-harmony---1.-Terminology-and-theory-l5kpy.pdf）。なおこのモデルは原録音の採譜ではなく、独自の32音旋律による実装実験。

## 入力旋律と和声選択
4/4で各小節4分音符4つ、8小節＝32音（MIDI番号）：
- m1: 64,65,67,68（E–F–G–G♯）
- m2: 69,71,72,71（A–B–C–B）
- m3: 69,68,67,65（A–G♯–G–F）
- m4: 64,62,60,64（E–D–C–E）
- m5: 67,69,71,72（G–A–B–C）
- m6: 74,72,71,69（D–C–B–A）
- m7: 67,65,64,62（G–F–E–D）
- m8: 60,62,64,60（C–D–E–C）

C6構成音の旋律にはC6（C,E,G,A）、非和声音D/F/G♯/Bにはdim7（D,F,G♯,B）の転回形を割当てる。**この8小節はCのトニック・ペダル的な和声化であり、ii–V–Iの機能進行ではない**。この段階で「32個の複雑なコード進行」を発明したと誤認しない。

## 生成と実行結果
コード：`jazz_piano_techniques/code/block_chords_8bar_v2.py`。
- 各旋律音をトップに固定し、同一pitch class集合から残り3声を直下1オクターブ内に配置（four-way close）。
- C6型19和音、dim7型13和音、合計32和音。トップ保持、4声の異なるpitch class、外声の幅が12半音未満、各和音の構成音集合を**PythonでassertしてPASS**。
- 例：E4トップのC6配置＝(55,57,60,64)＝G3–A3–C4–E4。F4トップのdim7配置＝(56,59,62,65)＝G♯3–B3–D4–F4。G4トップのC6配置＝(57,60,64,67)＝A3–C4–E4–G4。
- dim7トップから次のC6トップへ2半音以内で接近するイベントが**13件**。ただし**トップの解決のみ**の検査であり、4声すべての解決品質を証明しない。
- 別途、最初のC6和音(55,57,60,64)への半音下のparallel chromatic approach=(54,56,59,63)を検査。各声部+1半音で到達するが、**dim7 approachと混同しない**。
- locked-handsの旋律下オクターブ重複を32イベント生成し、重複音が4声の最低音より低いことを検査。

## 和声とボイシングの批判的監査
1. **dim7は常にドミナントの代用ではない**。C6–dim7のスケール内交替は、トニックの延長・線的和声化として機能しうる。G7(♭9)の根音省略形と同じ音集合でも、ベースや拍位置で機能は変わる。
2. **C6にはmaj7 Bを同時に含めない**。この実験でBはdim7のトップとして扱い、Cmaj7(maj7)とC6の共存を勝手に仮定しない。
3. **強拍上のdim7**は経過和音として不安定になりうる。本モデルは4分音符等間隔で強拍もdim7になり、実演上の最適化は未実施。弱拍・16分音符への再配置とタイ／休符の設計が必要。
4. **内声の平行5度・8度と低音の濁り**は未検査。4声の縦の構成音監査だけで「禁則なし」とは宣言しない。
5. **旋律の情緒的起承転結**は不足。32音は手法を検証するための試験旋律であり、完成作品ではない。
