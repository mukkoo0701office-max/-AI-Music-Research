## 2. 操作的定義と分類
実音の昇順列 P=(p0,…,pn) に対し span=max(P)-min(P)。この研究では **span>12半音**を「開離」候補とする。ただし音域の広さだけではジャズ的機能を保証しない。各音を {bass,guide,colour,melody,approach} にタグ付けし、和声・音域・リズムを別レイヤーで評価する。drop2/3はclose-positionからの特定変換であり、spreadの部分集合にすぎない。USTは上部の和音構造に関する分類であり、spreadと直交する。低音に単なる完全5度を積むだけで自動的にspreadの好例とはしない。

## 3. 具体的な独自生成例（歴史的採譜ではない）
C major の ii–V–I を以下の実音に配置する。
- Dm9: LH D3(50), C4(60) / RH F4(65), A4(69), E5(76)。音度=1,♭7,♭3,5,9。span=26。
- G13: LH G2(43), F3(53) / RH B3(59), E4(64), A4(69)。音度=1,♭7,3,13,9。span=26。5度は省略。
- Cmaj9: LH C3(48), B3(59) / RH E4(64), G4(67), D5(74)。音度=1,7,3,5,9。span=26。
この例は各コードの広がりを示すが、LH根音 D3→G2→C3 の跳躍、上声 E5→A4→D5 の大きな動きがある。**最小移動の優良例とは評価しない**。ii→VのF4→F3を同一声部の解決と呼ぶこともできない。ガイドトーンは Dm7のC→G7のB（半音下降）、G7のF→Cmaj7のE（半音下降）を、オクターブ移動・声部再割当と区別して監査する必要がある。

## 4. 和声機能・時間・誤用
- 根音を弾くソロピアノと、ベーシストが根音を担うアンサンブルで、同じspreadを無条件に使い回さない。前者は低音の和声識別、後者は低域衝突回避を優先。
- V7の3度/♭7の導音・下方解決は機能的要件。9/13などの色彩音は上声の旋律・解決先に従い、全コードで固定テンションを強制しない。
- リズムは独立パラメータ：旋律のロングトーン下の遅延内声、裏拍の短い上声応答、ベース先行の分散アタック、終止直前の密度縮退を区別する。全音を全拍同時に鳴らす固定パターンは避ける。これらは**生成上の設計案**であり特定録音のリズム記述ではない。
- 低音域の短2度/長2度の長時間持続、旋律直下の無目的な倍音衝突、ガイドトーンの省略、ベースとピアノLHの重複、開離を目的化した不自然な跳躍を減点する。低音の5度禁止は普遍的禁則ではなく、文脈依存の推奨として扱う。

## 5. 作編曲アルゴリズム仕様 v1
入力 `{key, chords:[root,quality,extensions,function], melody:[pitch,onset,duration], bass, ensemble, phrase, tension_curve, register_limits}`。
1. 旋律の構造音と非和声音の準備・解決先を確定し、強拍に保持すべき旋律音をトップに固定する。
2. 低音の担当を `piano_solo|bass_player|cello_cb` から決め、根音・3度・7度の機能を割当。低音の過密を避ける。
3. 和音ごとに和声音・許容テンションから候補集合を生成。span>12の候補を抽出し、ガイドトーン、旋律音、最低音の機能タグを保持。候補は同じpitch-class集合でも実音レジスターを変えて複数生成。
4. 各声の時間的連結を動的計画法で最適化。スコア `w1*guide_resolution + w2*melody_continuity + w3*voice_motion + w4*register_collision + w5*unresolved_nct + w6*rhythmic_monotony`。各項目は符号と正規化を明示して実装すること。共通音維持・半音解決は声部ID単位で検査し、集合間の最近傍距離だけで声部進行と称しない。
5. 弦6: Vn1=主旋律、Vn2=上部ガイド/色彩、Vn3=単純な持続・限定的移動、Va=内声半音解決、Vc=機能的低音と対旋律、Cb=必要時の根音補強。Cb欠員時はVcの低音を優先し上声の密度を縮小。divisiは明示し、各声部の可奏音域・弓替え・音価を別途監査。
6. 例外処理: 倚音・係留・経過音・裏コード・借用和音は和声ラベルと実音の解決先を別々に保持。意図的な衝突は `intentional_rub` とし、自動禁則で削除しない。
7. 出力メタデータ `{pitches,spellings,register,degree,role,voice_id,attack,release,function,resolution_target,source_status,unresolved}`。音響の良否は算術テストと独立。

### 7.2 定義の厳密化
span>12 は**研究内の操作的な広域配置フラグ**であり、歴史的・一般的なspreadの必要十分条件ではない。単純なroot+octaveもこのフラグを満たすが、豊かな開離和音とは限らない。そこで `spread_candidate = span>12 && distinct_functional_roles>=2 && upper_chord_tones>=2` を初期フィルタとする。これは**本研究独自の提案**であり、普遍的分類基準ではない。ベース単独のオクターブ重複を除外する一方、意図的な二声開離は別カテゴリー `two_voice_open` に保持する。

**drop2**は閉離4声の上から2声目を12半音下げる*操作*。結果の広がりと音楽的適否は別判定。**spread**は複数オクターブの実音配置に関する*状態*。したがってdrop2→spreadはよくあるが、同値ではない。ガイドトーンの配置・内声の連続性・リズム上の発音順を一つのラベルに潰さない。

### 7.3 和声機能を保持する生成
入力のコード記号から `required_degrees`（例: V7は3,♭7）と `optional_degrees`（9,13など）を分離する。メロディに9th倚音がある場合、伴奏に同じ音を無条件に重複しない。V7→Iの典型例 G7→Cmaj7 は、B→C と F→E の**二つの異なる声部**の解決を明示する。上声に9th Aを置くときは、A→G または A→B など、旋律線の目的に応じた継続先を選ぶ。Aが必ず特定の音へ解決するとは規定しない。

実音を持つ状態 `S_t={voice_id,pitch,degree,role,hand_or_instrument,onset,offset}` とし、候補間遷移を二部マッチングで最適化。ただし声部IDの維持が原則であり、声部交換には明示的ペナルティを与える。スコアは `cost = 4*unresolved_required_guide + 2*melody_disruption + 1*sum(abs(delta_pitch)/12) + 3*low_register_collision + 2*unprepared_strong_beat_dissonance + 1*rhythmic_repetition`（各項は非負、係数は暫定）。**単なる全体span最大化を目的関数に入れない**。強拍の倚音・意図した摩擦にはタグ付き例外を設ける。

### 7.4 具体例：C major ii–V–Iの修正版（独自設計、採譜ではない）
Dm9: bass D3, upper F3–C4–E4–A4（1,♭3,♭7,9,5）。G13: bass G2, upper F3–B3–E4–A4（1,♭7,3,13,9）。Cmaj9: bass C3, upper E3–B3–D4–G4（1,3,7,9,5）。ii→VでF3とE4とA4を保持し、C4→B3の半音解決を与える。V→IでF3→E3、B3保持（maj7）、E4→D4、A4→G4を声部ID別に対応付ける。B3→C4を敢えて採用しないので、**Vの導音が主音に解決したとは主張しない**。ガイドトーンを保留してmaj7に共通音化する選択と、導音解決の選択は別の候補として比較する。低音のD3→G2→C3は4度・5度関係の機能的移動であり、内声の滑らかさと分離して評価する。

### 7.5 時間設計と弦楽6声への翻訳
spreadは垂直配置のラベルであり、演奏時間構造を規定しない。旋律先行→中声の遅延応答、ベース先行→上声後打ち、終止直前の上声集約を独立したイベント系列として生成する。弦6ではCbを低音機能、Vcを中低域の進行、Vaを3度/7度、Vn3を長音主体、Vn2を上部色彩、Vn1を旋律に割当。Cb不在時はVcを低音へ再割当し、Va/Vn2が不足したガイドトーンを補う。ピアノの両手に跨る一つの開離和音を弦に分散しても、各声部の**旋律的連続性**を保つこと。divisiと弦の実音域は別途機械検査する。

### 8.2 独自生成器の厳密仕様 v3
状態を和音記号でなく `(voice_id,pitch,spelling,degree,function,onset,offset,role,instrument)` の集合とする。各候補に対し (a)音度の文脈的適合、(b)必要ガイドトーン、(c)トップ旋律との衝突、(d)低音の帯域、(e)声部ID継続、(f)解決時刻を評価する。span>12は**記述フラグ**に限定し、品質スコアには加点しない。drop2は4声closeから第2上声を1オクターブ下げる変換で、結果が音楽的に開離するか別判定。音高クラス一致だけでガイドトーン解決を認定しない。

和声遷移は強拍上の機能を維持しつつ、和音内の非和声音（倚音、係留、経過音）を `source_degree→target_degree@time` で明記する。旋律先行なら伴奏は後打ち/休止を候補に加え、各拍に和音を機械的に敷き詰めない。フレーズ境界では密度を変え、共通音の保持と内声半音移動を別々に最適化する。

弦6への写像ではVn1旋律、Vn2色彩/対旋律、Vn3易しい持続、Vaガイドトーン、Vc独立した低音/オブリガート、Cb任意の基礎低音。Cb不在ならVcに根音機能を再割当し、和声識別が弱くなる場合はVa/Vn2の配置を再最適化する。弦の分離発音とピアノの減衰を同一音響効果とみなさない。
