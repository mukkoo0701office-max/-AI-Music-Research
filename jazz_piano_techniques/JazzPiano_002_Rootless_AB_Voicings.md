# Jazz Piano 002 — Rootless A/B Voicings（基礎・声部連結）
研究日：2026-11-21。既存 JazzPiano_001 と Feedback_001 を確認。状態：理論的構成を検算済み、実演音響は未検証。

## ■ 今回のテーマ
ルートレスA/B。ベース奏者が根音を担当する場面で、ピアノは3rd/7thを核として9th/13thを含む4声を中域に置く。A/Bという名称は教材で揺れるため、本稿では「A=3rdから積む配置、B=7thから積む配置」と明示する。機能が優先で、形の暗記は二次的。

## 1. 本質と音楽的役割
ii–V–I のガイドトーンは iiの7th→Vの3rd、Vの7th→Iの3rd に半音で解決できる。ルートレスは低音を空け、上部声部の滑らかな移動を確保する。単独ピアノでは低音の根音を適時補う。

## 2. 音の並びと構造のルール
Key C、低音順、例示は教育用の独自配置：
- Dm9 A: F3–A3–C4–E4 = 3–5–7–9
- G13 B: F3–A3–B3–E4 = ♭7–9–3–13
- Cmaj9 A: E3–G3–B3–D4 = 3–5–7–9
この組合せは「共通音2つ以上を維持して必ず全声部が半音」という意味ではない。Dm9→G13 は F3/A3/E4 を共通保持、C4→B3半音下降。G13→Cmaj9 は F3→E3半音、A3→G3全音、B3保持、E4→D4全音。声部の交差なし。
より標準的なルートレス四声の一例：Dm9 F3–C4–E4–A4 (3–7–9–5)、G13 F3–B3–E4–A4 (♭7–3–13–9)、Cmaj9 E3–B3–D4–G4 (3–7–9–5)。上声の大きな移動を許すかは旋律と音域次第。9thや13thの省略・重複は音楽的に選ぶ。

## 3. 具体的な実践例
LHがルートレス、RHが旋律を担当する場合、LH: Dm9 F3–C4–E4–A4 → G13 F3–B3–E4–A4 → Cmaj9 E3–B3–D4–G4。RHはこれらと衝突しない位置に旋律を置く。低音楽器：D2→G2→C2。9thや13thは根音と一緒に低域へ密集させない。リズムのスウィングは和音構成とは独立して決める。

## 4. よくある間違い
- ベース不在でも常時根音を省略し調性の支柱を失う。
- 3rdと7thを同時に抜いてテンションだけを積む。
- 同じA/B形を平行移動し、共通音と半音解決を捨てる。
- 13thと♭13、9thと♭9を文脈なく重ねる。
- ジャズの平行ブロックコードを古典対位法の禁則から無条件に免除する。

## 5. 作曲・編曲への応用
Feedback_001の E♭maj9 | Gm7→C7(♭9) | Fm9→B♭13 | E♭maj9/G を対象に、機能的な内声の半音と共通音を先に設計し、予測困難な転調を追加しない。弦6ではCb/Vc根音、VaとVn2で3rd/7th、Vn3は共通音、Vn1は旋律、残る音を9th/13thに割り当てる。3rd/7thの保持・解決と平行5度/8度を別監査する。

## 6. 第二次研究：A/Bフォームの声部最適化と適用条件（2026-11-21）

### 6.1 既存例の再監査：音名と度数を切り分ける
前節の例は教育用の変種であり、「A=3rdから積む／B=7thから積む」という本稿内の定義を採用する。ただし**A/Bの呼称と厳密な音集合は教材・流派で一致しない**。音の順序を名称だけから推測する実装は禁止する。特に既存の Dm9 A = F–A–C–E は 3–5–♭7–9 であり、G13 B = F–A–B–E は ♭7–9–3–13、Cmaj9 A = E–G–B–D は 3–5–7–9。すべて根音抜きの4声だが、前者と後者は典型的な「3–5–7–9」型、中央は「7–9–3–13」型である。これらを同一の固定間隔テンプレートで平行移動してはならない。

### 6.2 2種類の声部連結を明示
**例I：最小移動に寄せた独自4声配置（Key C、低音順）**
- ii Dm9: LH F3–A3–C4–E4 = 3–5–♭7–9
- V G13: LH F3–A3–B3–E4 = ♭7–9–3–13
- I Cmaj9: LH E3–G3–B3–D4 = 3–5–7–9
- ベース: D2→G2→C2（別声部、ピアノ独奏ならLHの低音打鍵を別タイミングで補う）。
- 4声の対応: Dm→G: F→F (0), A→A (0), C→B (-1), E→E (0)。G→C: F→E (-1), A→G (-2), B→B (0), E→D (-2)。**合計絶対半音移動量は1+5=6**（両遷移、固定した低音順の声部対応で評価）。この数字は和声の「品質点」ではなく、限定された配置間の運動量である。
- 解決の核: iiの♭7=C→Vの3=B、Vの♭7=F→Iの3=E。Vの3=BはIの7=Bとして保持可能。ただし**Vの3がIの7へ保持されること自体は、すべての旋律で必須ではない**。

**例II：共通音を優先する別のCmaj9終止**
- G13: F3–A3–B3–E4 → Cmaj9: E3–G3–B3–D4。E4→D4とA3→G3は全音、F3→E3は半音。3rd/7thの明瞭さと上声の歌いやすさの折衷。
- Iで9th D4がメロディE4と衝突するなら、Cmaj7(9)の構成を保ちながら RH の旋律とLHの内声を再配置する。**メロディ優先で、同一音高の重複や長2度の配置を条件付きにする**。

### 6.3 異なるキーでの移調検証：Key F の ii–V–I
ベース G2→C2→F2。
- Gm9: B♭3–D4–F4–A4 = ♭3–5–♭7–9
- C13: B♭3–D4–E4–A4 = ♭7–9–3–13
- Fmaj9: A3–C4–E4–G4 = 3–5–7–9
- 声部: B♭→B♭→A (0,-1), D→D→C (0,-2), F→E→E (-1,0), A→A→G (0,-2)。合計移動量6半音。各コードの音名・機能はKey Cの例を完全長2度ではなく完全4度上へ移調したもの（C→F）。異名同音表記は調号に合わせる。

### 6.4 機能と旋律の競合を解決する優先順位
1. 現在のコードとメロディを確定。**メロディがすでに3rd/7thを担うなら、伴奏で同じ機能音を重複する必要はない**。
2. 低音担当の有無を確認。ベース奏者が根音を示すならルートレス可。ピアノ独奏で根音を終始消すことは原則避ける。
3. 3rdと7thを優先し、前後和音との共通音保持と半音解決を設計。
4. 9th/13thを加える。メジャーIの11thを無条件に持続させるなど、旋律との非意図的な短9度・長7度の衝突を監査する。
5. 低音の密集、手の実際の到達範囲、主旋律の帯域をチェック。テンションは常に4音必要という規則ではない。
6. 音楽的な拍節配置（先取り、後打ち、休符、音価）を別工程で決める。**4声が滑らかでもそれだけではスウィングしない**。

### 6.5 作編曲アルゴリズム（生成規則、擬似コード）
```text
input: chords, melody, bass_available, instrumentation
for each chord:
    guide = {third, seventh}
    candidates = enumerate_rootless_4_note_voicings(guide, optional={9,13,5},
                 register=[MIDI_53, MIDI_76], unique_pitches=True)
    if not bass_available: require_explicit_root_support_elsewhere()
    reject candidates with undefined_guide_function
    reject avoidable melody_conflicts and severe_low_register_clusters
for each adjacent chord pair:
    map individual voices preserving order when possible
    movement_cost = sum(abs(next_pitch[i] - prev_pitch[i]))
    add_penalty_for_voice_crossing, unprepared_tension, register_clash
select a sequence minimizing cost subject to melodic/harmonic constraints
audit guide-tone resolutions, bass, voice independence, rhythmic density
output: chord symbols + explicit pitches + provenance + validation status
```
これは**設計上のアルゴリズム案**であり、実装済み・全12キー検証済みという意味ではない。固定音域MIDI53〜76は仮の候補生成範囲であり、実演や編成によって変える。最小移動量だけを最適化すると平板な響きになり得るため、フレーズ頂点、対旋律、意図的な跳躍も別の目的関数で扱う。

### 6.6 弦楽6声への移植
- Cb（任意）: 根音をpizzで提示。Vcが独立ベースを担えばCb抜きでも成立。
- Vc: 根音／経過低音。ピアノの左手4音をそのまま低音に移すことはしない。
- Va・Vn2: 3rd/7thを分担。iiの7th→Vの3rd、Vの7th→Iの3rdの半音を優先。
- Vn3: 1音の共通音を長音で保持、または休符。難しい8分音符の内声移動は避ける。
- Vn1: 歌唱的旋律。メロディが9th/13thを担う場合、伴奏の重複は削除可能。
- 6声への展開では**和音4声＝弦4人の同時奏**と機械的に解釈しない。音域・音色・ボウイング・休符を考慮して役割を分散する。
- 声部監査: 古典的な平行5度/8度は別途検出し、ジャズ的な平行ブロック奏法との意図を区別。ルートレスだから禁則が自動的に解決するわけではない。

### 7.2 教則資料の対照：フォーム名より音集合と声部対応を優先
公開教則 **The Jazz Piano Site** は、Key C の Aフォームを Dm9 F–A–C–E → G13 F–A–B–E → Cmaj9 E–G–B–D、Bフォームを Dm9 C–E–F–A → G13 B–E–F–A → C6/9 A–D–E–G と具体的に示す。参照：https://www.thejazzpianosite.com/jazz-piano-lessons/jazz-chord-voicings/rootless-voicings/
- **重要な訂正**：前節までの「B=7thから積む」という説明は「iiコードにおけるBフォームの出発形」を意味するに過ぎず、**進行中のすべてのコードで最下音が7thになるわけではない**。BフォームのVでは3rdが最下音になる。
- **重要な区別**：BフォームのIを C6/9（A–D–E–G）とする教則例は、Imaj9（E–G–B–D）と異なり長7度Bを含まない。どちらを採用するかは旋律・次の和音・解決の性格で選ぶ。「BフォームはAフォームの同一構成音の単純転回形」と固定するのは不正確。
- 同資料は根音を省いた配置の多義性も指摘する。F–A–C–Eは Dm9 のルートレスであると同時に Fmaj7 の全構成音である。したがって、**ベースの根音・前後の機能・旋律**を伴わない分類器は和音機能を一意に確定できない。
- **PianoGroove** はA/Bの基本原理と、ドミナントで5thを13thへ置換する実用性を解説する。https://www.pianogroove.com/jazz-piano-lessons/rootless-chord-voicings/
- **Mark Levine, The Jazz Piano Book** は左手ボイシングを含むが、出版社の紹介ページで章の存在を確認したのみで、**書籍本文・譜例を直接読んでいない**。https://www.ejazzlines.com/jazz-piano-book-the-mark-levine-pdf

### 7.3 A/Bフォームの具体的声部進行（Key C、低音順）
A経路：
- ii Dm9 LH F3–A3–C4–E4 (♭3–5–♭7–9)
- V G13 LH F3–A3–B3–E4 (♭7–9–3–13)
- I Cmaj9 LH E3–G3–B3–D4 (3–5–7–9)
- ii→V: 0,0,-1,0 semitone。V→I: -1,-2,0,-2 semitone。合計絶対移動量6半音。

B経路：
- ii Dm9 LH C4–E4–F4–A4 (♭7–9–♭3–5)
- V G13 LH B3–E4–F4–A4 (3–13–♭7–9)
- I C6/9 LH A3–D4–E4–G4 (6–9–3–5)
- ii→V: -1,0,0,0。V→I: -2,-2,-1,-2。合計絶対移動量8半音。BのC6/9では属7のF→E半音解決を含むが、Iの長7度Bは鳴らさない。
- A/Bは絶対移動量だけで優劣を決めない。BのA4最高音が旋律に近すぎる場合、Aを採用するかレジスターを再配置する。B経路の表記は説明用で、実演家本人の録音採譜を意味しない。

### 7.4 12調の機能検査（実行済み）
内部のJavaScript検査をこの研究時に実行。12個の主音 pitch class について、Aフォームのii→Vで共通音3つとC→B相当の半音下降、V→IでVの♭7→Iの3rd半音下降およびVの3rd=Iのmaj7共通音を検査した。**12/12調で検査条件を通過**。これは移調した音度関係の検証であり、各調の正しい異名同音表記・オクターブ・指使い・聴感を検証したものではない。
- Key C: Dm9 F–A–C–E / G13 F–A–B–E / Cmaj9 E–G–B–D
- Key F: Gm9 B♭–D–F–A / C13 B♭–D–E–A / Fmaj9 A–C–E–G
- Key E♭: Fm9 A♭–C–E♭–G / B♭13 A♭–C–D–G / E♭maj9 G–B♭–D–F
**例外**：長調ii–V–Iの機能検査は短調iiø–V7(♭9)–iやオルタード・ドミナントにそのまま適用できない。別の音集合と禁則監査が必要。

### 7.5 生成アルゴリズム（仕様）
入力：コードの根音/質/機能、旋律（音高・発音時刻）、ベース有無、音域、前後の和声、編成。
1. **音集合生成**：iiは3–5–♭7–9、Vは3–♭7–9–13、Iは3–5–7–9または6–9–3–5。音名は調性に応じた綴りを保持。
2. **候補展開**：A/Bを単独コード名でなく進行全体の経路として列挙。転回・オクターブ移動は許可し、根音と伴奏の衝突はペナルティ。
3. **声部対応**：保持音=0、半音解決=低コスト。声部交差、低音の密集、メロディとの長2度/短9度、非意図的な最高音突出、過密な和音リズムを個別評価。
4. **機能検査**：ii♭7→V3、V♭7→I3の半音解決を候補評価に組み込み、旋律や借用和音により例外を許す。Iの6/9はmaj7を要求しない。
5. **リズム生成**：和音の形からスウィングを推論しない。休符、先取り、弱拍の発音、ベース・旋律との応答を別の時間軸で計画。
6. **構成**：2小節のii–Vと1小節のIをフレーズ単位で変奏し、旋律動機・和声リズム・テクスチャーを統合。移動量最小化だけでは平板になるため、頂点への計画的なレジスター上昇を許可。
7. **検証**：各候補の音度、音域、声部移動、コード機能、旋律との衝突を検査。弦6声ではCb/Vcの根音、Va/Vn2のガイドトーン、Vn3の持続音、Vn1の旋律へ機能を分散。禁則を別途監査。
