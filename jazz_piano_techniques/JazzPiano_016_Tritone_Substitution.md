## 2. 音度・和声機能の厳密な核
C長調の ii–V–I: Dm7–G7–Cmaj7。G7=(G,B,D,F)、代理D♭7=(D♭,F,A♭,C♭)。共通の実音は B≡C♭ と F。**機能上の3度と7度が入れ替わる**。G7のB(3)→C、F(♭7)→Eに対し、D♭7のC♭(♭7)→C、F(3)→E。両者の実音による半音解決を保持できるが、異名同音の綴り・和音の根音・5度・テンションは同一ではない。

低音 D→G→C の完全4度/5度系を D→D♭→C の半音下降に変える。**低音の線とガイドトーンの機能保持を別の評価軸とする**。D♭7→Cmaj7 は subV7/I→I であり、D♭をCの通常の属音と同一視しない。主和音Cへの到達が弱ければ単なる半音下行の平行和音として聞こえ得る。

### 2.1 代理コードの色彩は同一ではない
D♭7のA♭(5)はG7基準では♭9、D♭(根音)はG7基準では♭5/♯11、D♭7の9th E♭はG7の♭13、13th B♭はG7の♯9に対応し得る。**D♭7のすべてのテンションが無条件にG7altと等価ではない**。D♭7の♯11=Gを含めるとG7の根音に一致するが、スケール集合の一致と機能・綴り・強拍での旋律適合は別。D♭7の通常の11th G♭はG7のmaj7相当となり、G7altの標準的構成と混同しない。

### 2.2 異調での独立理論例
- C長調: Dm7 → D♭7 → Cmaj7。代理ガイドトーン F/C♭、到達 E/C。
- F長調: Gm7 → G♭7 → Fmaj7。代理ガイドトーン B♭/F♭(=E)、到達 A/F。
- B♭長調: Cm7 → C♭7(=B7の実音) → B♭maj7。代理ガイドトーン E♭/B𝄫(=A)、到達 D/B♭。異名同音の記譜上はC♭7の7度がB𝄫であることに注意。実務上B7と綴る場合は機能ラベルと記譜を分離する。
これらは**独自に構成した理論例であり、特定録音の採譜ではない**。

## 3. 声部進行・旋律・リズム
4声ピアノの独自試験モデル（低音は別声部）：Dm7上声 [F3,A3,C4,E4] → D♭7上声 [F3,A♭3,C♭4,E♭4] → Cmaj7上声 [E3,G3,B3,E4]。同一voice_idで F→F→E、A→A♭→G、C→C♭→B、E→E♭→E の軌跡。最後のE♭→Eは隣接半音上行で、旋律のEとの衝突・拍節・和声ラベルを別途監査する。**上声の最短移動だけでは美しさを保証しない**。代理コードのC♭はCへの導音的接近とする別配置も可能で、ここではBへ保持する別解を採用している。

拍節: 4/4でDm7を1–2拍、D♭7を3–4拍、Cmaj7を次小節1拍に置くのは一候補。代理コードを4拍裏だけに短縮するとアプローチ和音の色が強まり、2拍以上保持すると独立した支配和音として聞こえやすい。拍位置・長さは曲のメロディとフレーズで選ぶ。固定旋律がG7のD(5)を強拍で長く保持する場合、D♭7では♭9相当となるため無条件に置換しない。旋律がCに解決するBやFを持つ場合は候補となる。

## 4. 生成アルゴリズム v1（設計のみ、統合実装未了）
入力: harmonic_events, melody_fixed, bass_events, key_context, allowed_substitution, metric_grid, voices, ranges, phrase_target。
1. **候補生成**: 元コードがdominant7機能で、明示された解決先がある場合にroot+6 semitonesのdominant7を候補にする。すべてのdominant7に機械適用しない。
2. **音度綴り**: 元和音と代理和音の3rd/7thを機能別に保持し、実音pcと異名同音綴りを別フィールドで管理。
3. **旋律優先**: 固定旋律の強拍実音と代理和音の3/7/テンションの衝突を評価。許容倚音には解決音・時刻を付与。
4. **ベース**: 前後のroot motionを計算。下降半音連鎖を報酬とするのはフレーズ方向が一致するときだけ。ベースが元のVを保持するなら、代理コードの上声だけを重ねる複調的緊張として別候補に分類。
5. **時間的声部**: 声部ID固定、guide-tone保持・半音解決・共通音・旋律独立性・内声クリシェ・和声密度を個別にスコア化。無意味な半音往復、低域短2度、旋律との未解決衝突は減点。
6. **選択**: original V7 / subV7 / subV7(♯11) / V7alt を別候補として比較し、原曲の旋律・機能・音域・時間を最も保つものを選ぶ。候補なしも許す。
7. **ピアノ**: 左手シェル/ルートレスの低域衝突を検査し、ベース奏者の有無で根音配置を変える。右手旋律の音価とアクセントは固定。
8. **弦楽6声**: Vn1固定旋律、Vn2対旋律、Vn3易しい持続和声音、Vaガイドトーン/内声、Vc代理根音またはオブリガート、Cb任意の低音。Cb不在時はVcの低音役割を再配置。ピアノの短い代理アタックを弦の持続にそのまま移植せず、係留・解決時刻と音域を再監査。
9. **出力監査**: 元/代理の機能、guide-tone写像、ベース、旋律衝突、未解決非和声音、音度綴り、候補採否理由をログ化。

## 5. 誤用・反例
- 同じトライトーンを共有するからといって、元V7の全テンションや旋律が自動的に代理和音へ適合するとみなす。
- 代理D♭7のC♭をBと読み替えた結果、楽譜上の音度を取り違える。
- D♭7→Cmaj7の半音ベースだけを根拠に機能的終止と断定する。
- 旋律に元V7の5度Dが長くあるのに、D♭7上での♭9緊張と解決を設計しない。
- V7altとsubV7のテンション集合・音響・ベース機能を同一視する。
- 長調ii–V–Iの成功例を、マイナー終止、ブルースのI7、モーダル・ペダルへ無条件に転用する。
- 古典和声の増六和音との異名同音関係を、歴史的な直接由来の証明と混同する。
