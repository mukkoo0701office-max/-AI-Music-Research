# Jazz Piano 003 — Bud Powell: melodic-line / sparse-left-hand architecture

- Hank JonesのSmithsonian oral history https://amhistory.si.edu/jazz/Jones-Hank/Hank_Jones_Transcript.pdf — Powellの右手中心の演奏スタイルに関する同時代奏者の証言。

## 音楽原理
1. **非対称な情報密度**：右手は長い8分音符の線を維持し、左手は各和声の機能を最低限の音で示す。両手を同時に高密度にしないことで、主旋律の運動を明確にする。
2. **左手の音数より和声タイミング**：コードの変化点で毎回必ず打鍵するのではなく、旋律がフレーズを切る位置・低音が根音を示す位置・ドラムのアクセントと合わせて和音を置く。強拍／裏拍の一方を絶対規則にしない。
3. **ガイドトーンの連続**：root+3rd/7thの低密度シェルでも、右手がテンションと経過音を担うことで全体として豊かな和声になる。ピアノ単独時とベースありの編成で根音の必要性が変わる。
4. **不協和の時間設計**：右手の非和声音を左手の和音に対して単純に禁じない。倚音・クロマチックアプローチ・解決先をタグ付けし、非和声音が目標音へ収束する時間的文脈を監査する。これはUCLAのDeMottaによる旋律／和声リズムの相互作用の議論に沿うが、以下の具体例は独自生成。

## 独自の生成実験（Pythonで実行済み）
C major ii–V–I、3小節、右手は各小節8個の8分音符（合計24音）、左手は各小節1回だけ2音シェル（合計3打鍵）。各コードの根音と3rd/7thを含む候補を総当たりし、隣接する和音の声部移動と右手との近接を罰する暫定スコアで最小化。
- 候補数：Dm7=3、G7=2、Cmaj7=4。
- 選択結果（MIDI番号、低声→高声）：(38,60)=(D2,C4)、(43,59)=(G2,B3)、(48,59)=(C3,B3)。
- コスト11、構造テストPASS。
- 右手音列は**独自の試験用データ**であり、Powellの演奏から採譜した旋律ではない。
- 右手との衝突ペナルティは各小節との同時刻整合ではなく全体の近接を数える**粗い代理指標**。発音時刻、和声外音の解決、旋律のフレージング、リズムのスウィング比は未実装。

## 作編曲への展開
- 旋律は3rd/7th/9thなどの目標音から逆算してクロマチックアプローチを配置。根音と5度だけで拍頭を埋めない。
- 左手は**発音回数・ガイドトーンの品質・音域・右手の隙間**を別の制約として最適化。
- 弦6声へ転用する際は、Vn1に歌う単旋律、Cb/Vcに低音、Va/Vn2/Vn3にガイドトーンを分配し、すべてのパートを同時に細分化しない。

## 品質監査・次回
本回は資料に基づく書法の定義と**限定的な構造検証**。歴史的演奏の直接採譜、右手旋律のクロマチックアプローチ生成、拍位置を含む不協和解決の実測、音楽性評価は未達。次回02/03では実際の採譜資料に照合し、右手のエンクロージャーと左手のオフビート配置を8小節単位で研究する。03/03終了後は別テーマへ移行。
