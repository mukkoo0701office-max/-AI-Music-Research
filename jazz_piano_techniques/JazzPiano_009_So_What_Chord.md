## 2. 和声・音度の正確な区別
五声形のインターバル・ベクトルは下から **[5,5,5,4] 半音**。この**構造形**と**根音に対する和声機能**は別変数。
- `E–A–D–G–B`：Eを仮の根音とすれば **1–11–♭7–♭3–5 = Em11(no9)**。Dベース上では **9–5–1–11–13**。D Dorian上の色彩であり、この五声だけではF（短3度）もC（短7度）もない。
- `D–G–C–F–A`：Dを根音とすれば **1–11–♭7–♭3–5 = Dm11(no9)**。二つの形の結合音集合は {D,E,F,G,A,B,C} = D Dorianの全音集合。
- したがって「両者はDm11の同一転回形」は誤り。Em11型→Dm11型という**ダイアトニック全音下降の二和音応答**と、同じ形を別のDorian中心へ**半音移調**する形式境界の操作を区別する。
- 形式はAABAの32小節（D Dorian 16 / E♭ Dorian 8 / D Dorian 8）。セクション転換は和音進行の機能的V–I終止ではなくモード中心の変更。

## 3. 声部進行と対位法
上記五声を一対一対応させると全5声が **-2半音**（E→D, A→G, D→C, G→F, B→A）。これは全声の平行移動であり、古典対位法的な独立声部進行の理想とは異なる。ジャズの色彩的なplaningとして許容する場合も、他の旋律・ベースの対位法は独立に設計する。上下二和音の差は半音でなく**全音**。D中心からE♭中心への移調は**+1半音**だが、そこで全音下降の内部応答関係は保存できる。

ベースがDを保持する間に上声がEm11型→Dm11型と変わると、先行形のB(13)が後続形のA(5)へ下行し、先行形のE(9)がD(1)へ収束する。一方、後続形はF(♭3)とC(♭7)を明示するため、応答で短調の同定が強まる。これは**理論的解釈**であって録音中の具体的なタイミングやダイナミクスの実測ではない。

## 4. リズム・形式・歴史的作品例
歴史的参照はMiles Davis《So What》のベースの呼びかけと管・ピアノの応答。和音を毎拍繰り返す一般コンピング・パターンとして抽象化すると、原曲の休止と呼応の構造を失う。作編曲では `bass_call → upper_response → space` のイベントを別々に生成し、応答の位置をフレーズ境界に関連付ける。正確なアタック時刻・音価・各奏者の配分は録音・原譜未照合のため未確定。Bill Evansの実演を特定の拍に捏造して帰属させない。

## 5. 生成アルゴリズム v1（仕様のみ）
入力 `{mode_tonic, mode_pitch_set, bass_events, melody_events, response_windows, ensemble, ranges, harmonic_role, style}`。
1. モードの全7音を異名同音情報付きで保持し、候補五声を音程型 `[5,5,5,4]` で生成。各音の**和音仮根音**に対する度数と**実ベース**に対する度数を別々に計算する。
2. Dorian中心で基準応答の二形を `tonic+2` 起点と `tonic` 起点で作り、全声下降2半音のペアを生成。必ずモード内7音と二形の和集合を監査。これは《So What》から抽象化した**独自生成規則**で、全曲の実演を自動転写する規則ではない。
3. 形式境界で新中心へ全体を移調し、前後のモード名と転調距離を別途記録。全音応答と半音モード変更を混同しない。
4. ベース・メロディを優先固定し、和声応答を呼びかけの後に配置。低域の短2度・声部交差・旋律との半音衝突・不要な連続アタックをスコア化。強拍/弱拍の選択はフレーズ構造によって決め、録音から未確認のリズムを固定しない。
5. スタイル切替: modalでは平行声部を許容するが、機能的ii–V–Iでは3rd/7thの解決線を独立ハード制約とし、五声型を機械的に当てはめない。
6. 出力には `source_status`, `harmonic_interpretation`, `mode_fit`, `range_check`, `collision_check`, `verified_by_audio` を持たせる。検査未実施フラグはfalse。

## 6. ピアノ・弦楽6声への転用
ピアノではベース奏者の有無で根音補強を分岐。五声全てを中低域に押し込まず、低二声と上三声の間隔を調整する。ただしオクターブ配置の変更は音程型そのものを変えるため「同一ピッチクラス／異なるレジスター」と記録。
弦6（Vn1, Vn2, Vn3, Va, Vc, Cb）ではCbの呼びかけ、Vn1の主旋律、Vn2/Va/Vc/Vn3の応答和声を**時間差**で配置。五声が同時に必要な場合はVn1も一時的に応答へ参加するか、Cb以外の五声を用いるが、主旋律の欠落は許容条件を明記。Vn3は長音中心、Cbは休止区間を許容。Cb不在時はVcへベース機能を委譲し、応答の五声を省略・再配分する。係留・倚音の解決は発音時間軸で検査し、単なる全声平行の恒常化を避ける。

## 8. 誤用・自己監査・次回引継ぎ
- E–A–D–G–BをDベース上で「1–11–♭7–♭3–5」と説明するのは誤り（それはE根音時）。二つの基準形を混同しない。
- 全音の応答と半音のセクション転換を混同しない。
- 平行移動を「対位法の禁則なし」と断定しない。古典様式とジャズ様式で判定規則を分ける。
- 同じ構造形でもベースが変われば機能が変わる。モードの適合だけでは旋律との衝突を保証しない。
- **品質ゲート未達**: 原盤ライナーノーツの直接閲覧、Levine図12-2と音楽学論文図版の逐音確認、1959年録音との時刻付き照合、12調の音名綴り、生成器統合試験、実音響。一次資料に直接照合できていないため「完成」とは呼ばない。
