## 2. 和声・音度の正確な区別
五声形のインターバル・ベクトルは下から **[5,5,5,4] 半音**。この**構造形**と**根音に対する和声機能**は別変数。
- `E–A–D–G–B`：Eを仮の根音とすれば **1–11–♭7–♭3–5 = Em11(no9)**。Dベース上では **9–5–1–11–13**。D Dorian上の色彩であり、この五声だけではF（短3度）もC（短7度）もない。
- `D–G–C–F–A`：Dを根音とすれば **1–11–♭7–♭3–5 = Dm11(no9)**。二つの形の結合音集合は {D,E,F,G,A,B,C} = D Dorianの全音集合。
- したがって「両者はDm11の同一転回形」は誤り。Em11型→Dm11型という**ダイアトニック全音下降の二和音応答**と、同じ形を別のDorian中心へ**半音移調**する形式境界の操作を区別する。
- 形式はAABAの32小節（D Dorian 16 / E♭ Dorian 8 / D Dorian 8）。セクション転換は和音進行の機能的V–I終止ではなくモード中心の変更。

## 3. 声部進行と対位法
上記五声を一対一対応させると全5声が **-2半音**（E→D, A→G, D→C, G→F, B→A）。これは全声の平行移動であり、古典対位法的な独立声部進行の理想とは異なる。ジャズの色彩的なplaningとして許容する場合も、他の旋律・ベースの対位法は独立に設計する。上下二和音の差は半音でなく**全音**。D中心からE♭中心への移調は**+1半音**だが、そこで全音下降の内部応答関係は保存できる。

ベースがDを保持する間に上声がEm11型→Dm11型と変わると、先行形のB(13)が後続形のA(5)へ下行し、先行形のE(9)がD(1)へ収束する。一方、後続形はF(♭3)とC(♭7)を明示するため、応答で短調の同定が強まる。これは**理論的解釈**であって録音中の具体的なタイミングやダイナミクスの実測ではない。

## 4. リズム・形式・歴史的作品例
歴史的参照はMiles Davis《So What》のベースの呼びかけと管・ピアノの応答。和音を毎拍繰り返す一般コンピング・パターンとして抽象化すると、原曲の休止と呼応の構造を失う。作編曲では `bass_call → upper_response → space` のイベントを別々に生成し、応答の位置をフレーズ境界に関連付ける。正確なアタック時刻・音価・各奏者の配分は録音・原譜未照合のため未確定。Bill Evansの実演を特定の拍に捏造して帰属させない。

## 5. 生成アルゴリズム v1（仕様のみ）

2. Dorian中心で基準応答の二形を `tonic+2` 起点と `tonic` 起点で作り、全声下降2半音のペアを生成。必ずモード内7音と二形の和集合を監査。これは《So What》から抽象化した**独自生成規則**で、全曲の実演を自動転写する規則ではない。
3. 形式境界で新中心へ全体を移調し、前後のモード名と転調距離を別途記録。全音応答と半音モード変更を混同しない。
4. ベース・メロディを優先固定し、和声応答を呼びかけの後に配置。低域の短2度・声部交差・旋律との半音衝突・不要な連続アタックをスコア化。強拍/弱拍の選択はフレーズ構造によって決め、録音から未確認のリズムを固定しない。
5. スタイル切替: modalでは平行声部を許容するが、機能的ii–V–Iでは3rd/7thの解決線を独立ハード制約とし、五声型を機械的に当てはめない。
6. 出力には `source_status`, `harmonic_interpretation`, `mode_fit`, `range_check`, `collision_check`, `verified_by_audio` を持たせる。検査未実施フラグはfalse。

## 6. ピアノ・弦楽6声への転用
ピアノではベース奏者の有無で根音補強を分岐。五声全てを中低域に押し込まず、低二声と上三声の間隔を調整する。ただしオクターブ配置の変更は音程型そのものを変えるため「同一ピッチクラス／異なるレジスター」と記録。
弦6（Vn1, Vn2, Vn3, Va, Vc, Cb）ではCbの呼びかけ、Vn1の主旋律、Vn2/Va/Vc/Vn3の応答和声を**時間差**で配置。五声が同時に必要な場合はVn1も一時的に応答へ参加するか、Cb以外の五声を用いるが、主旋律の欠落は許容条件を明記。Vn3は長音中心、Cbは休止区間を許容。Cb不在時はVcへベース機能を委譲し、応答の五声を省略・再配分する。係留・倚音の解決は発音時間軸で検査し、単なる全声平行の恒常化を避ける。

### 9.1 出典照合と証拠限界
- 音楽分析論文「Pitch class hierarchies in Miles Davis' 'So What': Reconsidering modal jazz improvisation with computer-based analysis tools」公開本文 https://www.academia.edu/73588330/Pitch_class_hierarchies_in_Miles_Davis_So_What_Reconsidering_modal_jazz_improvisation_with_computer_based_analysis_tools は、ベースの短い4句を a–a'–a–a'' と説明し、応答を E–A–D–G–B → D–G–C–F–A と明記。Em11→Dm11だけでなく A9sus4/E→G9sus4/D、またA9sus4/E→Dm11の擬似V–Iとしても解釈可能とする。**論文の検索公開テキストを照合したのであり、原録音や図版の直接逐音検証ではない。**

- Bill Evansの1959年ライナーノーツの16+8+8説明は原盤画像ではなく https://jazzintro.com/2018/12/19/active-listening-in-jazz-4/ に掲載された画像・引用を介して確認。一次資料そのものの現物精査ではない。

### 9.2 単なる全音下降以上の構造
- D Dorian音集合 {D,E,F,G,A,B,C} において先行形の B（長6度）はDorianの特徴音で、後続形のF（短3度）とC（短7度）は短調性を補強する。**各形の垂直的和声同定と、二形の水平的合成で得るモードの同定を別々に評価**する。
- 二形の上声は5本すべて全音下降するが、ベース・コールはその並進に従属しない。構成原理は「和音平行＋独立したベース句＋休止」の階層的な対位法である。
- 和声機能ラベルは固定しない。候補集合 `{Em11→Dm11, A9sus4/E→Dm11, A9sus4/E→G9sus4/D}` を記録し、ベースDの持続、局所Aの強調、旋律終止の位置に応じて事後評価する。理論上の候補であって、歴史的演奏の唯一の正解ではない。
- 「E♭はAの裏コード根音なのでB部は機能的裏ドミナント」という読みは研究論文に現れる**解釈仮説**であり、Dorianのモード切替を古典的V–Iの必然と見なさない。

### 10.2 三層の和声表現と反例
(1) **絶対音高構造**: 基準形は E3–A3–D4–G4–B4 と D3–G3–C4–F4–A4 のように、同一オクターブ関係を仮定すると下から [5,5,5,4] 半音の五声構造となる。ここでのオクターブ番号は**生成器の例示**であり原録音の実音域の主張ではない。
(2) **モード中心への度数**: D中心では先行形 [9,5,1,11,13]、後続形 [1,11,♭7,♭3,5]。この度数は上下の音高順に並べたものであり、同じ音をE根音のEm11と解釈した度数とは異なる。
(3) **機能解釈**: Dの持続ベースではEm11/D→Dm11/Dのような色彩変化として聴き得る。A9sus/Eなどの別名は文脈依存の仮説であり、Aのドミナント機能が実際に確立した証拠ではない。**反例**: ベースがEを強く確立すれば先行形はEm11として聞こえ、Dorian中心Dの呼応とは限らない。B部のE♭ Dorianへの半音上昇は、V–Iの強制的解決ではない。

### 10.3 旋律・対位法・リズム・形式を持つ生成規則 v3（仕様）
入力 `{section_mode, phrase_boundaries, bass_motif, melody, voicing_template, attack_windows, texture_density, ensemble_ranges, harmonic_hypotheses}`。
1. **形式**: 16+8+8小節のモード領域を確定する。Dorianの7音集合と、D→E♭→Dの中心遷移を別変数に格納する。原曲由来の形式を汎用の必須テンプレートとしない。
2. **ベース動機**: 各句の呼びかけを主音・5度・経過音・休符の有限状態として設計し、同じ2小節セルの無変化反復を避ける。句末の音高とリズムの変化を先に確定し、和音はその空白に応答させる。
3. **五声応答**: `V(t)=[t+2,t+7,t+12,t+17,t+21]` → `W(t)=[t,t+5,t+10,t+15,t+19]` （tはD3など実音高の主音）。全5声が-2半音で移る。両者のピッチクラス和集合はDorian7音。ただし**旋律と低音が和音の一部を共有する場合は重複を省く**。この場合は元の厳密五声形と区別する。
4. **旋律優先**: 倚音・係留・経過音は拍位置と解決先で分類。和音との短2度を一律禁止せず、低域・長時間・強拍での無解決衝突に高い罰則を与える。Dorian特徴音の長6度を全区間で鳴らし続けない。
5. **声部連結**: 五声平行は**局所的な音色操作**と定義し、連続区間の他声部（ベース/旋律）に反行・斜行・休止を許す。古典和声の平行完全音程禁則をこの局所効果に機械適用しない一方、厳格対位法モードでは別の禁則検査を行う。
6. **リズム**: `call → response → space` をイベントグラフとして生成。応答を全小節に自動配置しない。強拍・シンコペーション・先取りの選択は旋律句と密度予算に従い、原盤未照合の具体的リズムを「歴史的正解」として固定しない。
7. **ピアノ/弦6**: ピアノではベース奏者の有無で低音を再配分。弦6ではCb=呼びかけ、Vn1=旋律、残り4声=縮約応答を既定とし、五声の完全再現が必要な局面のみVn1を和音へ合流させる。Vn3は原則長音中心、VcとCbの低域密集を避ける。Cb不在の場合のVcへのベース委譲はテクスチャを再最適化する。
8. **候補評価**: `mode_coverage, bass_melody_independence, voice_crossing, register_mud, unresolved_dissonance, phrase_space, style_fidelity` を独立出力。各指標の重みは未較正であり、総合点の高さを音楽的正しさと同一視しない。
