## 2. 定義・分類（コード記号だけで機能を決めない）
完全減七は根音から {0,3,6,9} 半音の4音集合。C♯°7 = C♯–E–G–B♭。C♯はDmの根音Dへの導音、EはDm7の9thまたはDmの構成外音、GはDm7の11thまたはFへ解決可能、B♭はDm7のAへ半音下降可能。**四声すべてがDm7の構成音に自動的に解決するわけではない**。具体的な声部配置と到達和音を先に指定する。

A. 上行型：C6→C♯°7→Dm7。低音 C→C♯→D。C♯°7はvii°7/iiと読める（Dmへの副次導音）一方、低音のクロマティックな連結としても聴取され得る。C♯°7をA7♭9の根音省略形と見る場合はA低音やA7の機能文脈を別途要求。単なる音集合の一致だけで機能を断定しない。

B. IV–♯IV°–V：Fmaj7→F♯°7→G7（C調）。F♯–A–C–E♭ はGへ向かうvii°7/V。G7に対し F♯→G、A→BまたはG、C→B、E♭→Dなど解決選択がある。低音 F→F♯→G。到達G7の3rd=Bと7th=Fを明示して属機能を成立させる。

C. 下降型：Em7→E♭°7→Dm7（C調）。E♭°7 = E♭–G♭–A–C。ベースE→E♭→Dは半音下降だが、E♭°7がDm7の副次導音という説明は不適切。線的接近・対位法的経過を第一候補にし、機能ラベルは前後文脈で検証する。

D. 共通音減七：C6→D°7→C6等は単純な上行根音経過とは別のトニック装飾候補。D°7 = D–F–A♭–C♭(実音B)。C6のC/E/G/Aと共通する実音はないため、この具体形を「共通音減七」と**無条件には呼べない**。共通音型を採用するなら、Cを含む C°7 = C–E♭–G♭–B𝄫（実音A）等、保持する声部とその機能を実際に検証する。Barry Harris 6th-diminishedの交替和音も、通常の副次導音とは独立の理論として分類。

## 3. 声部・リズム・旋律
経過dimは「根音が半音だから適合」ではない。強拍固定旋律と減七の実音、長い係留の解決時刻、低音での短2度衝突、他声部との声部交差を検査する。C6→C♯°7→Dm7で固定旋律C5をdim上に長く保持すればC♯との半音摩擦が起こり得る。短い弱拍の接近と強拍を跨ぐ持続を別判定する。4/4の一例はC6を1–2拍、C♯°7を3–4拍、Dm7を次小節1拍。弱拍4裏だけの挿入も候補だが実作品の固定法則ではない。

### 具体例と機能
- C6→C♯°7→Dm7：C♯–E–G–B♭はvii°7/ii。C♯→D、E→F、G→F、B♭→Aという解決ではD–F–F–Aとなり、Dm7の7th Cが不足する。全声を半音・全音解決するだけで到達和音が完成すると仮定しない。声部増減、解決の跳躍、テンションの保持を個別に評価。
- Fmaj7→F♯°7→G7：F♯–A–C–E♭はvii°7/V。F♯→G、E♭→Dは重要だが、G7の3rd Bと7th Fの担当声部を別途検証する。
- Em7→E♭°7→Dm7：前版のE♭–G♭–A–Cは実音の便宜表記。厳密な三度堆積はE♭–G♭–B𝄫–D𝄫（実音E♭–F♯–A–C）。E♭→Dは下降であり、E♭をDの導音とするのは誤り。
- C6→C°7→C6：C°7 = C–E♭–G♭–B𝄫（実音A）。C6との共通音はCとA。CとAを保持しE♭→E、G♭→Gとすればトニック装飾になる。副次導音型とは区別。
- 完全減七の短3度対称性は音高類集合の同一性を示すだけで、異名同音の綴り・根音機能が同一とは示さない。

### 原理の精密化：機能は音集合でなく有向声部・時間で決まる
1. 上行 C6→C♯°7→Dm7 は C♯→D という副次導音、ベースC→C♯→Dを備える。ただし C♯°7=(C♯,E,G,B♭) を Dm7=(D,F,A,C) に四声全て近接移動させるには、C♯→D、E→F、G→A、B♭→C（各+1,+1,+2,+2半音）という**一つの可能な完全な到達配置**がある。これを唯一の歴史的奏法とみなさない。別解 C♯→D、E→F、G→F、B♭→A は到達音D,F,F,Aで7thを欠く。到達和音の必須音充足と声部移動最小化は別の目的関数である。
2. IV→♯IV°→V（F→F♯°7→G7）は、F♯→GとE♭→Dを使うだけではG7のB/Fを保証しない。F♯→F（半音下降）も可能だが、導音F♯の上行解決とは異なる解釈が必要。声部の「傾向」と「必ずそう動く」は区別する。
3. 下降 Em7→E♭°7→Dm7 は E→E♭→D のベース連結。E♭°7をvii°7/iiと呼ばない。音集合は異名同音で別の導音減七と一致し得るため、**下降というベース方向だけで非機能和音と断定することも禁止**。到達点・綴り・拍節・低音以外の解決を照合する。
4. C6→C°7→C6 は C°7=(C,E♭,G♭,B𝄫=A) と C6=(C,E,G,A) の共通音 C/A を保持し、E♭→E、G♭→G とするトニック装飾の**設計例**。C°7はC6と2音共通だが、C6→D°7→C6を同じ「共通音型」と呼ぶのは誤り。
5. 完全減七の対称性により12個の綴り上の根音に対してpitch-class集合は3個。根音名、声部機能、拍節、到達和音の区別を失うpitch-class-onlyモデルは不十分。
