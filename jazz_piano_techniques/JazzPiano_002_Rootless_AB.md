# Jazz Piano 002 — Rootless A/B Voicings / ルートレスA/B
研究日: 2026-11-21
状態: 基礎研究・第1回
前回: jazz_piano_techniques/JazzPiano_001_Shell_Voicings.md

## ■ 今回のテーマ
ベース奏者が根音を担当する状況で、ピアノ左手の3rd/7thと9th/13thを中心に構成するルートレス4声配置。A/Bは「3rdを下側に置く配置」と「7thを下側に置く配置」を区別する便宜的名称で、文献や教師により呼称は異なる。

## 1. 本質と音楽的役割
ルートを除くことで中音域の密集を避け、3rdと7thの機能を保持したままテンションを加えられる。ii–V–Iでは共通音と半音移動を優先。独奏で低音が不在の場合は根音が曖昧になるため、別の声部・拍でベースを補う。スウィングは配置音ではなく発音時刻、音価、アクセントの問題。

## 2. 音の並びと構造のルール
Key Cでの典型的なA/B配置（低音順）：
- Dm9: A形 F3–A3–C4–E4 = 3,5,7,9 / B形 C3–E3–F3–A3 = 7,9,3,5
- G13(9): A形 F3–A3–B3–E4 = b7,9,3,13 / B形 B2–E3–F3–A3 = 3,13,b7,9
- Cmaj9(13): A形 E3–G3–B3–D4 = 3,5,7,9 / B形 B2–D3–E3–A3 = 7,9,3,13
A/Bの厳密なラベルは体系によって揺れるため、実際のボイシングの音名と度数を優先する。G13(9)のA形はF–A–B–Eで、G7の3rd Bと7th Fを含む。Cmaj9(13)のB形は5thを省いて13thを加える。

## 3. 具体的な実践例（Key C、LH/RHの音名を低音順）
ベース奏者がD2→G2→C2を担当する前提：
- Dm9: LH F3–A3–C4–E4 / RH A4（旋律）
- G13(9): LH F3–A3–B3–E4 / RH G4（旋律）
- Cmaj9: LH E3–G3–B3–D4 / RH G4（旋律）
この配列ではDm9→G13(9)のF3/A3/E4は共通、C4→B3は半音下降。G13(9)→Cmaj9ではF3→E3、A3→G3、B3は共通、E4→D4。3rd/7thの動きが和声機能を明瞭にする。
低音と中音域の分離を確認する。右手旋律と左手最高音が衝突する場合は転回・省略する。

## 4. よくある間違い
- ベースなしでルートレスを使い、調性感の根拠を失う。
- 3rd/7thを省略し、9th/13thだけを残す。
- 低音域に4声を密集させて濁らせる。
- A/Bというラベルを唯一の絶対的定義として扱う。
- 機能和声の半音解決を無視して全声部を機械的に平行移動する。
- テンションを重ねればスウィングになると誤解する。

## 5. 作曲・編曲への応用
- ピアノ: ベース奏者がいる場合LHはF3–E4程度の中音域に配置。旋律の位置に応じて上下の声部を調整。
- 弦6声: Cbが根音、Vcが7thまたは低い3rd、Vaが残るガイドトーン、Vn2/Vn3が9th/13thまたは共通音、Vn1が旋律。Cb不在ならVcに根音を割り当ててガイドトーンを別声部へ。
- MusicXML: 各コードのrootと3rd/7thをタグ付け。rootlessを「全声部にrootなし」ではなく「ピアノLHにrootなし」として実装。隣接和音間の声部移動を半音単位で記録し、拍数・音域・交差・平行5/8・テンション解決を監査。
- 声部進行の判定は実際の音高とオクターブを使う。ジャズの意図的な平行配置とクラシック的な禁則を区別する。

# 研究第2回/最大3回：短調 iiø–V7(♭9,♭13)–i とガイドトーン最小移動
研究日: 2026-11-21。**累計2/3。** 次回はこのテーマを最大あと1回だけ扱い、その後は次の技法に移る。

## 目的と出典
第1回の長調ii–V–Iに対し、短調のiiø–V7alt–iで**ルートレス配置が本当に和声機能を保持し、4声の最小移動を実現できるか**を検証する。参考資料：Camden Hughes, *Basic A and B Jazz Piano Voicings* (https://cdn.learnjazzstandards.com/wp-content/uploads/2016/02/Jazz-Piano-A-and-B-1.pdf)。ここにはA/Bの各和音種の音度式が明記される。補助的な解説：https://cadenzalab.com/voicings/rootless-voicings および https://jazzify.jp/blog/type-a-type-b-rootless-voicings/ 。一次録音や実演譜の直接採譜は今回行っていない。したがって**歴史的な奏者固有の奏法の実証ではなく、教育的な和声モデルの検証**である。

## 機能と声部の実例：A minor
CbまたはベースがB1→E2→A1を提示する前提で、鍵盤左手の4音を以下のように配置（MIDI番号で検査）。
- Bm7♭5(9): D4–F4–A4–C♯5 = [62,65,69,73]。度数は♭3,♭5,♭7,9。**根音Bを含まない**。
- E7(♭9,♭13): D4–F4–G♯4–C5 = [62,65,68,72]。度数は♭7,♭9,3,♭13。**根音Eを含まない**。
- Am9: C4–E4–G4–B4 = [60,64,67,71]。度数は♭3,5,♭7,9。**根音Aを含まない**。

上声順の連結：
- Bm7♭5(9)→E7(♭9,♭13): [0,0,-1,-1] 半音、合計移動2半音。DとFは保持、A→G♯、C♯→C。
- E7→Am9: [-2,-1,-1,-1] 半音、合計移動5半音。D→C、F→E、G♯→G、C→B。
- E7の3rd G♯→Am9のGは半音下降であり、**導音G♯→Aという典型的な解決ではない**。この配置はガイドトーンの「古典的な機能解決」を保証しない。右手旋律でG♯→Aを別途実現する、またはAmの6th/9thや転回を変える必要がある。**最小移動と機能的解決は別の目的関数**。

## 生成アルゴリズムに落とすべき制約
1. 各コードの根音、3rd、7th、テンションのpitch classを定義。根音はベースが担当し、鍵盤の4声からは除く。
2. 3rd/7thを少なくとも1声ずつ保持する。ただし最終トニックをAm6/9に置換する場合は7th必須制約を緩和し、6thの色彩を明示する。
3. 各声部の隣接和音間の移動量合計を最小化。ただし**導音の上行解決、♭9の下行解決、旋律の目標音、音域の明瞭さ**を独立制約として採点し、最小移動だけを唯一の基準にしない。
4. 弦楽6声ではCb=B→E→A、Vc=根音補強または7th、Va=ガイドトーン、Vn2/Vn3=残りのガイドトーンとテンション、Vn1=解決を持つ旋律。音の重複は必ずしも悪くないが、低域の短2度や意図しない平行完全音程は監査。
5. ♭9 Fと♭13 Cの両方を含むE7では、F→E、C→Bという半音下降を声部進行の候補にできる。ただしこの解決先は**A minorのE（5th）とB（9th）**であり、主和音の3rd Cへの解決を意味しない。

## 内部検証
Pythonで上記3組のMIDI音高を実際に評価。Bø→E7の移動量[0,0,-1,-1]、合計2、E7→Am9の移動量[-2,-1,-1,-1]、合計5を確認。**これは和声構成音と声部移動の検査であり、録音・原譜との一致を証明しない。**

## 自己批評・未解決
- 既存の第1回にある「Dm9のA/B配置」や「G13のA/B配置」は慣習的な例であり、音域・楽器編成により優先順位が変わる。
- 上記Bøの9th C♯はA harmonic minorの自然なダイアトニック構成音ではなく、独自の色彩を持つ。短調iiøの標準テンションとして無条件に使用しない。自然な♭9 Cの採用も可能だが、根音Bに対して短9度となるため、実際の響きと文脈を監査する。
- 「ルートレス＝常に4声」ではない。密度の高い旋律や低域での濁りを避けるため3声・2声へ縮約する設計も必要。
- **次回（3/3）**：12調の音域制約、短調のガイドトーン解決、代替トニックAm6/9、テンションの実際の解決を多目的最適化し、その後は次の技法へ移行する。

# 研究第3回/最大3回【最終】：12調検証・短調トニックの選択・旋律との解決分担
研究日: 2026-11-21。**累計3/3。本テーマはこれで終了。次回は別の技法（バド・パウエル系の2声書法）へ移る。**

## 最終研究の問い
ルートレス・ボイシングの低い移動コストだけで音楽的な解決を設計できるか。結論：**できない**。低い移動コスト、和声の3rd/7thの保持、旋律導音の解決、低音域の濁り回避、形式的な緊張解放は異なる制約として管理する必要がある。

## 12調で再現可能な短調 iiø–V7alt–i の設計
Bø9 → E7(♭9,♭13) → Am9。ベースはB→E→A。4声は低音から：
- Bø9 = D4–F4–A4–C♯5 [62,65,69,73]（♭3,♭5,♭7,9）
- E7alt = D4–F4–G♯4–C5 [62,65,68,72]（♭7,♭9,3,♭13）
- Am9 = C4–E4–G4–B4 [60,64,67,71]（♭3,5,♭7,9）
- 代替のAm6/9 = C4–E4–F♯4–B4 [60,64,66,71]（♭3,5,6,9）。**短調主和音にmaj6を加える**ため、Am9の短7度Gとは色彩が異なる。

実際にPythonで実行した検証結果：iiø→Vの4声移動[0,0,-1,-1]、絶対値合計2半音。V→Am9は[-2,-1,-1,-1]、合計5半音。V→Am6/9は[-2,-1,-2,-1]、合計6半音。**12半音移調したすべての調で**音度構成、根音省略、3rd/7th（Am6/9のみ3rd/6th）、移動コストが不変であることをassertで検証した。

ただし**12調移調のテストは音域最適化ではない**。例えば高い調への単純移調は鍵盤左手の最適なレジスターを外れ得る。実用的な配置選択には転回、声部入替、オクターブ移動、旋律との音域衝突検査を加える必要がある。

## 声部進行と音楽性のトレードオフ
E7の3rd G♯4はAm9のG4に下降し、Am6/9のF♯4にはさらに下降する。いずれも**G♯→Aの導音解決を左手4声の対応では満たさない**。右手旋律または他声部にG♯→Aを設計すれば、左手のルートレス最小移動と旋律の機能的解決を両立できる。これは「和音単位で全声部を解決させる」のではなく**役割分担した対位法**として設計することを意味する。

生成アルゴリズムの評価関数例：
score = 0.30*voice_leading + 0.25*guide_tone_integrity + 0.20*melodic_resolution + 0.15*register_clarity + 0.10*texture_continuity。
**係数は設計例であり、原曲分析や知覚実験から推定したものではない**。最低限、3rd/7thの保持と独立した旋律解決の有無は別々に検査する。

## 弦楽6声への移植
CbはB→E→Aの根音進行、Vcは必要に応じて3rd/7thを補強、Va/Vn3/Vn2はルートレスの3声を分配、Vn1は導音の解決を持つ旋律。全員に4声のコードを重複させない。Cb欠席時にはVcに根音を割り当て、ガイドトーンをVa/Vn3へ移す。平行5・8度、低音密集、意図しない短2度、Vn3の難度を別途監査する。
