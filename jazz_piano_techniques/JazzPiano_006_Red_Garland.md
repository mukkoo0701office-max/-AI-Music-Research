# JazzPiano_006 — Red Garland: block chords and approach voicings (1/3)

## 研究対象と一次資料への距離
Red Garlandの特徴的な奏法を、**右手の旋律オクターブ＋内側の完全5度（下側の旋律音から完全5度上）**、**左手の中音域ルートレス4声**、**両手のリズム同期**として分離して扱う。これは一般的な4-way-close/Shearing型locked-handsと同一ではない。

参考文献：
- Riccardo Scivales, “Billy Boy and Red Garland's block chords style” https://www.riccardoscivales.com/billy-boy-red-garlands-block-chords-style/ — 転写に基づく説明。右手オクターブ＋内部完全5度、左手ルートレス、両手同期、内部音がコード外音となる場合を記述。
- John Valerio, *Jazz Journey: A Guide for Listening*, p.264, preview https://cognella-titles-sneakpreviews.s3-us-west-2.amazonaws.com/81208-1B-URT/Valerio_SP.pdf — 単音線から厚いブロックコードへの対比と左手ルートレスの歴史的文脈。
- Mark Levine, *The Jazz Piano Book*, ch.7, https://moodle.cegepsherbrooke.qc.ca/pluginfile.php/108871/mod_folder/content/0/Jazz%20Piano%20Book%20By%20Mark%20Levine.pdf?forcedownload=1 — ルートレス左手の一般的原理。Garland独自のリズム／音色をこれだけで証明できない。
- https://files01.core.ac.uk/download/pdf/161953202.pdf — 学位論文のRed Garland節、構造と非和声音の言及。

**方法上の制約**：今回、原録音を聴取して新規に採譜したわけではない。転写研究と教育文献の記述を照合し、独自の試験モデルを実装した。歴史的な「常に／必ず」の断定は避ける。

## 1. 構造と響きの機能
右手メロディのMIDI番号をmとすると、原型はRH=(m−12,m−5,m)。中声は下の旋律音から完全5度、上の旋律音から完全4度下。旋律が半音上行すれば右手3音を同じく半音上行させる。**コードの構成音を毎回再選択するのでなく、形状の連続性が優先**されるため、右手中声がその時のコード外音になる場合がある。こうした一時的なrubを、強拍の構造的な不協和と弱拍のアプローチで区別する必要がある。

左手は3rd・7th・9th・13thを含み得る中音域のルートレス和音。コードの根音と機能を左手だけで完結させる必要はないが、ソロピアノでは別途ベース音を設計しなければ和声の曖昧さが増す。

## 2. オリジナルのii–V–Iモデル（E♭ major）
Fm9: LH A♭3–C4–E♭4–G4（56,60,63,67）
B♭13: LH A♭3–C4–D4–G4（56,60,62,67）
E♭maj9: LH G3–B♭3–D4–F4（55,58,62,65）

右手はそれぞれ3音の独自試験旋律を使い、各音をオクターブ＋5度で厚くする。LHのFm9→B♭13ではA♭、C、Gの3声が共通でE♭→Dが半音下降し、ドミナントの3rdを準備。B♭13→E♭maj9ではA♭→G、C→B♭、D保持、G→Fで進む。**3rd/7thの機能的進行と共通音**を先に設計した。

## 3. Python実行検証
コード `jazz_piano_techniques/code/red_garland_006_v1.py` を実行。
- 3和音×3旋律音＝**9アタック**。
- 全9アタックで右手のオクターブと内部完全5度、左手4音の異なるpitch class、両手の音域分離をassertで検証しPASS。
- 実装した単純な音域上の隣接半音検出は**0件**。これはすべての和声的衝突がないことを意味しない。異なるオクターブのpitch class上の♭9などは別途監査が必要。
- 初回テストでは右手が低すぎてLHと重なり、assert失敗。右手を1オクターブ上げて再試験しPASS。**音域分離は音楽的に必要な条件**として明文化。

## 4. アプローチ研究の次の課題
1. 弱拍の旋律クロマチック・アプローチ時、RHの全3音を並行移動する場合と、内声のみ半音接近させる場合を区別。
2. ガイドトーンの係留・半音解決を、LH和音ごとではなくアタックごとに監査。
3. 右手中声のコード外音を「一時的rub」「拍をまたぐ未解決」「意図的な色彩」に分類し、時間・音域・音量を加えた指標を設計。
4. ソロピアノの低音・ペダル・休符を別レイヤーに設計し、7音を常時同時発音する単調な音楽を避ける。
5. 史料の説明と、独自アルゴリズムの出力を混同しない。

# 第2回（累計2/3）— Garlandの固定右手形と左手の機能的解決を分離する

## 史料監査・用語の精密化
Riccardo Scivales, “Billy Boy and Red Garland's block chords style” (https://www.riccardoscivales.com/billy-boy-red-garlands-block-chords-style/) は、同曲の転写を基に、右手の旋律オクターブ＋下声から完全5度上の内音、左手の主に4声のルートレス配置、左右のリズム同期を記述する。特に転写の第7・13・34小節で右手内音が和声に適合しない例を指摘している。これは**二次的な転写研究**であり、当研究では当該小節の譜面画像と原録音を逐音比較していないため、具体的な実音は断定しない。
Mark Levine, *The Jazz Piano Book*, ch.19, p.180（公開された章のテキスト https://www.redemption-church.com/worship/Songs/Real%20books/Other%20stuff/Sheet%20Music%20-%20The%20Jazz%20Piano%20Book.pdf ）はGarlandの7〜8音とShearing等のブロックコードを区別し、代表例としてMiles Davis *Milestones* の “Billy Boy”、Coltrane *Settin' the Pace* の “I See Your Face Before Me”、*Bahia* の “My Ideal” を挙げる。これらは**作品参照**であり、以下の音列を実演に帰属させない。

## 原理：垂直和声と線的「固定形」の非同一性
旋律トップmのRH三音は [m-12,m-5,m]。したがって旋律の変位Δmをそのまま3声に与える。旋律が和声音か否かとは独立に内声が動くため、内声の非和声音は設計ミスと直ちに判定できない。判断は (a) 構造拍/弱拍、(b) 直後の和声と旋律の解決、(c) 左手との実音程、(d) 音域・持続時間、(e) 意図的な音色の粗さ、で行う。和音ごとに右手の完全5度を「正しいテンション」に置換する操作は、Garland型の構造的同一性を破壊しうる。

LHは機能と線的接続を担う。先行モデル E♭ major の Fm9 [56,60,63,67] → B♭13 [56,60,62,67] → E♭maj9 [55,58,62,65] では、ii→Vの順序対応移動量は1半音、V→Iは**5半音**（1+2+0+2）。以前の一般化で6と計算してはならない。ii→Vの共通実音は3、V→Iは1。Fm9のE♭（♭7）がB♭13のD（3）へ半音下降し、B♭13のA♭（♭7）がE♭maj9のG（3）へ半音下降する。和音全体の最小移動と機能的ガイドトーン解決を別々に評価する。

## 生成器仕様 v2（実装可能な規則）
入力：メロディ(midi, onset, duration, metric_strength)、機能付きコード（root, quality, extensions, bass）、フレーズ境界、テクスチャー密度。
1. アタック候補を選ぶ。旋律の全音に和音を機械的に付けず、長音・到達音・機能転換・クロマチック接近の終点を優先。アプローチ音では「3音とも並行半音移動」「RH休止して単音」「LHのみ係留」の候補を並立させる。
2. RH=(m-12,m-5,m)を保持し、音域の重なり・旋律の位置を検査。低い旋律なら一律オクターブ移動せず、テクスチャーの一時的な解除を許す。
3. LHは3/7を優先して3〜4声候補を列挙。根音を外す場合はベースが機能を担うか確認。候補スコアは voice-leading cost + register collision + unresolved guide-tone + low-register semitone + excessive density。3/7の正しい機能解決を、単純な総移動量より高い優先度で制約する。
4. RH固定内声の非和声音は意図された摩擦として独立タグ付け。強拍で長く保続する場合には警告し、弱拍から目標音へ解決する場合は許容候補とする。**固定5度は全和音で協和するという前提を置かない。**
5. RHとLHの同時発音を基準としながら、休符・部分テクスチャー・単音線を句読点として選択。両手の同期は歴史的様式の特徴であり、全小節での連続発音を強制する意味ではない。
6. 出力監査：旋律トップ保持、RH 7/5半音構造、LH 3/7、和声の根拠、拍上の不協和、声部交差、音域、フレーズの密度を別々の指標で返す。楽譜や音源の自動生成を品質検査の代用にしない。

## 異なるキーの算術監査（この実行でJavaScriptを実際に評価）
上記LH 3和音をMIDIで半音0〜11移調し、計12系列の順序・共通実音・総移動量を検査した。**12/12で音高順序が正しく、ii→Vは1半音、V→Iは5半音、共通音は3/1**。最初の検査ではV→Iの期待値を誤って6と設定したため12件すべて失敗した。差分を確認し、正しい値5と修正した。この誤りを隠さず記録する。これはMIDI算術の検査であり、全12調の異名同音表記・楽器音域・原録音との一致を保証しない。
例：C majorに移すにはE♭モデルから-3半音。LHは Dm9 [53,57,60,64] → G13 [53,57,59,64] → Cmaj9 [52,55,59,62]。F majorには+2半音で Gm9 [58,62,65,69] → C13 [58,62,64,69] → Fmaj9 [57,60,64,67]。MIDI数字の実音表記と和音名の異名同音を別レイヤーで管理する。

## 弦楽6声への移植と誤用
Vn1は旋律、Vn2は旋律下オクターブまたは対旋律、Vn3は必要箇所で固定5度の長音化、Vaは3/7の解決、Vcは9/13や線的接続、Cbはベース機能を選択的に担う。**7音同時のピアノ形を6人にそのまま移すことは不可能**なので、重複の間引きと時間的分散を明示する。Vn3の簡易パート条件とVa/Vcの持続可能な声部を優先。ピアノの打撃的同期を弦の持続音へ移すと音響上のrubが増幅するため、固定5度を長く保持する場合はテンションの実音程と解決先を再監査する。
誤用：全拍での7音同時発音、低音域での密集配置、旋律の音域を無視したRHオクターブ、ベース不在で根音を常に省略、固定5度の摩擦を無条件に「禁則」として消すこと、逆に長い強拍の未解決摩擦をすべて歴史的Garland様式として正当化すること。
