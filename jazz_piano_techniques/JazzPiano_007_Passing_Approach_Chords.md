# JazzPiano_007 — Passing Chords / Approach Chords / Two-Detour Reharmonization（研究1/3）

2026-11-21。目的：隣接する小節の主和音A→Bの間に、**自然な経過和音を1〜2個**配置する。コード数の増加ではなく、到達点の明確さ・声部の半音移動・拍節上の説得力・旋律との整合性を評価する。Moon Riverの制作自体は保留し、汎用技法として研究する。

## 資料確認と区別
1. Berklee College of Music, *Let Your Ear and Your Heart Lead*: https://college.berklee.edu/bt/204/lesson.html 。原旋律から単純な和声を再確認し、ベース進行、感情上の意図、ii–Vチェーン、旋律間の動きでリハーモナイズする立場。**和声を過密化しない**。
2. Michael McClimon, *Transformations in Tonal Jazz: ii–V Space*, Music Theory Online 23(1), 2017: https://mtosmt.org/issues/mto.17.23.1/mto.17.23.1.mcclimon.html 。ii–V–I、裏コードとガイドトーンの関係を形式的に扱う。
3. 坪口昌恭「バリー・ハリス・ビバップ・メソッドの実践と応用」https://shobi-u.repo.nii.ac.jp/record/623/files/geijutsukiyou2802_re.pdf 。6th/dimを用いたコードネームだけに還元できない動きを説明。
4. Barry Harris Method, *First progressions to know* https://barryharrismethod.com/method/10.2 と *Borrowing* https://barryharrismethod.com/method/10.4 。6th→dim→dominant、diminished音の借用と解決。これは**既存曲の原曲進行を再現する主張ではない**。

## 分類：寄り道は機能別に選ぶ
- **Secondary dominant**：Cmaj9 → E7(♭9) → Am9。E7はAmのV7。到達点を強調。
- **ii–V insertion**：Cmaj9 → Bm7(♭5) → E7(♭9) → Am9。短調のiiø–V7–iとして一時的にAmへ向かう。2個の寄り道が機能的に結束する。
- **Tritone substitution**：Dm9 → D♭13 → Cmaj9。D♭7はG7の裏コードとして働くが、ベースの半音下降が重要。単なる半音上の同質和音とは区別。
- **Passing diminished**：C6 → C♯dim7 → Dm9。ベース半音上行と到達点への導音的引力。C♯dim7の各声部を実際にDm9へ解決する必要がある。
- **Borrowed iv minor**：Cmaj9 → Fm6 → C/E。E♭→E、A♭→G等の半音解決による陰影。これは同主短調借用で、必ずしも支配的なV–Iの引力ではない。
- **6th-diminished ornament**：C6 → Bdim7 → C6。トニック延長であって、別調への転調とは限らない。

## 2個の寄り道の独自試験モデル
### A：正統的なジャズの引力
|位置|コード|機能|
|---|---|---|
|第1小節頭|Cmaj9|出発 I|
|第1小節3拍|Bm7♭5|Amへのiiø|
|第1小節4拍|E7♭9|AmへのV7|
|第2小節頭|Am9|到着 vi / 一時的i|

4/4での試験配置。3/4なら第1小節2拍目裏→3拍目などに変える。Am9の旋律音がG（♭7）なら、E7のG♯を同声部で半音解決させるのは不適切なので、声部と旋律を別々に監査する。

### B：半音ベースの都会的な接続
|位置|コード|ベース|
|---|---|---|
|第1小節頭|Dm9|D|
|第1小節3拍|A♭13|A♭|
|第1小節4拍|D♭13|D♭|
|第2小節頭|Cmaj9|C|

A♭13はD♭13へのV7として扱える（A♭7→D♭7）、D♭13はG7の裏コードとしてCへ解決。**A♭→D♭→C** は五度進行＋半音下降であり、全体が半音ベースではない。誇張して「完全クロマチック下降」と呼ばない。

### C：泣けるグラデーション
Cmaj9 → Fmaj9 → Fm6 → C/E。寄り道はFmaj9とFm6の2個。A→A♭→G、C保持、E♭→Eなど、トップノートと内声を別々のタイミングで解決する。ドミナントで引っ張るのではなく、借用和音の情緒を利用する。

## 選択・監査アルゴリズム
1. 出発和音・到達和音・**固定メロディ音**・拍位置を入力する。
2. 1個／2個の経過候補を機能別に生成し、候補ごとに根音運動と3rd/7thの解決先を記録。
3. 各声部を近接配置し、共通音は保持、残りは原則半音／全音を優先。内声が無意味に上下を往復する候補を減点。
4. 旋律と経過和音の衝突を**拍単位**で検査。許容する倚音は解決時点を指定。コード外音を全て禁止しない。
5. 経過和音は弱拍や拍裏を優先するが、機能的なii–Vには強拍上の配置も許す。コードを増やすこと自体は加点しない。
6. ペダルは半音衝突がある箇所で踏み替え／浅踏みし、共通音の残響は保持。
7. 0/1/2寄り道案を同じ旋律で比較し、音楽的に不要なら0を採用する。

### 独自Python実験（実行済み）
4音の左手候補を音域E3–C5（MIDI 52–72）から列挙し、(a)4音の異なるpitch class、(b)3rd/7thに相当する指定ガイドトーン、(c)幅16半音以内、(d)C4未満で隣接短2度を禁止、の条件を課した。全和音の声部位置を固定し、隣接和音間の4声合計移動半音数＋5半音超の跳躍ペナルティを**動的計画法**で最小化した。単純な和声評価ではなく、同じ候補空間での**接続コスト**のみ。

- A0: Cmaj9→Am9：コスト0、同一ボイシング（G3–C4–E4–B4）を両コードに流用。**この時点でベースを明示しない限り到達感はゼロ**。
- A1: Cmaj9→E7♭9→Am9：コスト4。Cmaj9 (55,62,64,71) → E7♭9 (56,62,64,71) → Am9 (55,60,64,71)。3声の保持と半音移動。
- A2: Cmaj9→Bm7♭5→E7♭9→Am9：コスト8。Cmaj9 (55,62,64,71) → Bm7♭5 (57,62,65,71) → E7♭9 (56,62,64,71) → Am9 (55,60,64,71)。
- B0: Dm9→Cmaj9：コスト3。
- B1: Dm9→D♭13→Cmaj9：コスト6。Dm9 (53,57,60,62) → D♭13 (53,56,59,61) → Cmaj9 (52,55,59,62)。
- B2: Dm9→A♭13→D♭13→Cmaj9：コスト8。Dm9 (53,57,60,62) → A♭13 (54,56,60,63) → D♭13 (53,56,59,63) → Cmaj9 (52,55,59,62)。
- C0: Cmaj9→Cmaj9/E：コスト0。
- C1: Cmaj9→Fm6→Cmaj9/E：コスト6。
- C2: Cmaj9→Fmaj9→Fm6→Cmaj9/E：コスト10。Cmaj9 (55,60,64,71) → Fmaj9 (53,60,64,69) → Fm6 (53,60,62,68) → Cmaj9/E (52,59,62,67)。

**失敗からの修正**：当初、C/Eを3音集合{C,E,G}として入力したところ「異なるpitch classの4音」という条件を満たせずassert失敗。最終到達和音をCmaj9/E（C,E,G,B,Dを許容）に明示的に変更し、再実行で9パターンすべての候補生成・コード構成音assertが通った。C/EとCmaj9/Eは同一ではなく、**比較の和声目標を拡張した**ことを記録する。
